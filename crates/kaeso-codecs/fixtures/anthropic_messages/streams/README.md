# anthropic_messages / streams

Exact SSE bytes: `event: <type>` line, one-line JSON `data:` line, blank line. Data JSON is compact except `ping` (`{"type": "ping"}`) and the doc-copied `error` line, which keep the spaces the API sends. Every stream with a same-named file in `responses/` accumulates (concatenate text/thinking/signature deltas, append citations, parse joined `partial_json`, apply `message_delta` delta and usage) to exactly that response.
