# anthropic_messages / requests

Exact `POST /v1/messages` bodies (and `count_tokens/` bodies for `POST /v1/messages/count_tokens`). `<name>.headers.json` holds forwarded allowlisted headers for the request of the same name. The matching response/stream, where one exists, has the same base name.
