# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. Everyone who takes part in the project, in issues, pull requests, discussions or any other channel, is expected to follow it.

## Reporting

Report unacceptable behaviour to the maintainer at [conduct@kaeso.app](mailto:conduct@kaeso.app). Every report is reviewed and handled confidentially.

Security vulnerabilities are not conduct reports: report them privately as described in [SECURITY.md](SECURITY.md).
