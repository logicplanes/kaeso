# End-to-end tests

The official OpenAI and Anthropic Python SDKs, pinned in `e2e/requirements.txt`, against KPP's encoders (`e2e/conformance`, served by `crates/kpp-conformance`), the gateway (`e2e/sdk`) and a fresh install from `deploy/compose.yaml` (`e2e/install`). How to set them up and run them is in the documentation: [Testing › End-to-end tests](https://docs.kaeso.app/development/testing#end-to-end-tests).
