description: Connect OpenAI and Anthropic keys to an organization.

---

Provider keys belong to the organization. Each project uses the organization's default key for a provider unless another key is assigned to it.

## Add a key

Open the organization's **Providers** page and choose **Add key**. A key's requests count against the [rate limits](keys-and-limits.md#rate-limits) of the key that sent them.

## Assign keys to projects

Assign a key to the projects that should use it; the others keep the default.
