# Kaeso documentation

Everything about using, running, integrating and developing Kaeso, as Markdown pages in [`content/`](content) in English, German and Simplified Chinese, built into the static site at [docs.kaeso.app](https://docs.kaeso.app). How to write, check and translate a page is in [Writing documentation](content/en/development/documentation.md), how the site works in [Documentation site](content/en/development/architecture/docs-site.md), and the rules for changing it are in [AGENTS.md](AGENTS.md).
