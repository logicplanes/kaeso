**MCP 服务器**列出组织的项目可以从中获取工具的服务器。每一行显示服务器的地址、简称、Kaeso 的连接方式、工具以及使用它的项目。查看此页面需要 `mcp_servers.view`，更改需要 `mcp_servers.manage`（[MCP 门户](../concepts/mcp-portal.md)解释了各个部分）。

## 添加服务器

1. 打开 **MCP 服务器**，选择**添加服务器**。
2. 输入服务器的 Streamable HTTP 地址，例如 `https://mcp.example.com/mcp`，然后选择**检查地址**。Kaeso 会显示服务器自称的身份、MCP 版本、登录方式以及列出的工具数量。
3. 保留或更改名称和简称。简称是服务器的工具对客户端的前缀，例如 `x__create_post`。
4. 选择 Kaeso 的登录方式：**无需登录**、**密钥请求头**或 **OAuth 登录**，以及账户是**共享**还是**每个人自行登录**。
5. 对共享的密钥请求头，输入请求头的名称和值。对共享的 OAuth，选择**登录**该服务器：登录会在新标签页中打开，您返回后，对话框会显示**已连接为**该账户。
6. 选择项目应提供的工具。只读工具已选中，破坏性工具会被标出。除非服务器由您自己控制，否则请保持**保留变更的工具待审核**开启。
7. 选择使用该服务器的项目，然后选择**添加服务器**。所选工具会在这些项目中开启。

私有网络中的地址只有在实例通过 `mcp_servers.allowed_networks` 允许该网络时才能使用（见[配置](../self-hosting/configuration.md)）。纯 `http` 只能在这些网络中使用。

如果服务器的授权服务器既不接受客户端元数据文档，也不接受注册，对话框会要求输入客户端 ID；对机密客户端，还需输入其密钥。请在那里用重定向 URI `https://kaeso.example.com/oauth/upstream/callback` 注册 Kaeso。

## 重新登录或替换密钥

选择一个服务器以打开其侧滑面板。在**连接**下，**重新登录**会开始新的 OAuth 登录，**替换密钥**会设置新的请求头。拒绝 Kaeso 登录的服务器会显示**已退出登录**，直到有人重新登录。

对需要每个人自行登录的服务器，侧滑面板不会列出连接：每个人在**账户** › **连接**下连接自己的账户。第一个人连接后，服务器的工具就会出现。

## 审核变更的工具

服务器变更了一个保留待审核的工具时，侧滑面板会显示有多少工具在等待，该工具会显示**已变更**和**审核**。审核会显示标题、描述、输入和输出 schema 以及提示的变化，并附上已批准定义和当前定义的哈希。

- **批准变更**会批准您审核过的定义。开启了该工具的项目会再次提供它。
- **保持关闭**会继续保留该工具，并在所有项目中关闭它。

如果服务器在您批准前再次变更该工具，则不会批准任何内容，您需要审核新的变更。

## 更改服务器

- **检查新工具**会立即向服务器询问其工具，而不必等到下一次检查。
- **选择项目**设置使用该服务器的项目。每个项目仍会选择自己的工具。
- **编辑**可以重命名服务器、更改其简称，或开启和关闭**保留变更的工具待审核**。新的简称会为客户端重命名每个工具。
- **删除**会移除服务器及其登录信息和工具。所有项目的门户都不再提供它们。
