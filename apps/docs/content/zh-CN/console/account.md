您的账户位于侧边栏底部菜单中的**账户**下，包含以下页面：

| 页面 | 内容 |
| --- | --- |
| 个人资料 | 头像、名称、邮箱地址和账户 ID，以及删除账户 |
| 安全 | 密码、双重验证和恢复码 |
| 会话 | 您已登录的浏览器 |
| API 密钥 | 您在所有项目中的密钥（见 [API 密钥](api-keys.md)） |
| 成员身份 | 您所在的组织及其项目、您的角色，以及退出组织 |
| 通知 | 接收哪些邮件 |
| 外观 | 主题和语言 |

## 更改邮箱地址

在**个人资料**下选择**更改邮箱**，输入新地址。Kaeso 会向新地址发送确认链接，并通知旧地址。打开链接后更改才会生效。

## 更改密码

在**安全**下，**更改密码**会设置新密码，并让您的其他会话退出登录。如果您只使用登录链接或单点登录，就没有密码，可以通过**设置密码**添加一个。

## 开启双重验证

双重验证会在每次使用密码登录时要求输入身份验证器应用中的验证码。登录链接和单点登录不需要验证码。

1. 在**安全**下选择**设置**。
2. 用身份验证器应用扫描二维码，或输入设置密钥。
3. 输入应用显示的六位验证码，然后选择**开启**。
4. 保存控制台只显示一次的 10 个恢复码：复制它们，或选择**下载 .txt**。每个恢复码可代替应用验证码登录一次。

**重新生成**会替换恢复码，**关闭**会移除双重验证。如果身份验证器和恢复码都已丢失，实例管理员可以为您重置双重验证。

## 退出其他浏览器的登录

**会话**列出您已登录的每个浏览器以及登录方式。**结束会话**会让其中一个退出登录，**全部退出登录**会让除当前浏览器外的所有浏览器退出登录。

会话在 7 天未使用后结束，最长不超过 30 天。

## 确认敏感操作

某些操作要求在最近 15 分钟内登录过。如果您的登录时间更早，控制台会在执行操作前要求您重新登录。

- 在您的账户中：更改邮箱地址、在没有密码时设置密码、关闭双重验证、重新生成恢复码以及删除账户。
- 在组织中：[权限](../concepts/rights.md)中标注为需近期登录的权限所对应的操作，例如添加服务商密钥、创建平台密钥或删除日志。
- 作为实例管理员：将某人设为实例管理员或取消、删除用户、重置用户的双重验证以及任命组织所有者。

## 选择接收的邮件

在**通知**下，**预算提醒**和**即将过期的密钥**可开启或关闭相应邮件。安全相关邮件（例如密码已更改的通知）始终会发送。

## 选择主题和语言

在**外观**下：

- **主题**可选**系统**、**浅色**或**深色**，保存在当前浏览器中。
- **语言**可选自动、English、Deutsch 或简体中文。自动会跟随浏览器语言；控制台不支持该语言时使用英语。选择会保存到您的账户，因此会同步到其他浏览器，Kaeso 发送的邮件也会使用该语言。

产品名称和模型 ID 在所有语言中保持不变。

## 退出组织或删除账户

**成员身份**下的**退出组织**会让您退出该组织及其项目，并归档您在其中的密钥。

**个人资料**下的**删除账户**会让您退出所有组织，并归档您的所有密钥。历史记录中会显示为已删除的用户。输入您的邮箱地址进行确认。

如果您是某个组织的最后一名所有者，这两项操作都无法进行。请先让其他人成为所有者。
