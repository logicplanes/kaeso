您的账户位于侧边栏底部菜单中的**账户**下，包含以下页面：

| 页面 | 内容 |
| --- | --- |
| 个人资料 | 头像、名称、邮箱地址和账户 ID、管理该账户的组织，以及删除账户 |
| 安全 | 密码、双重验证、恢复码和单点登录关联 |
| 会话 | 您已登录的浏览器 |
| 智能体 | 您通过 [MCP 服务器](../api/mcp.md)连接的智能体，以及它们的权限和活动 |
| API 密钥 | 您在所有项目中的密钥（见 [API 密钥](api-keys.md)） |
| 成员身份 | 您所在的组织及其项目、您的角色，以及退出组织 |
| 连接 | 您在需要每个人自行登录的 MCP 服务器上的账户（见 [MCP 门户](../concepts/mcp-portal.md#连接)） |
| 通知 | 接收哪些邮件，以及何时接收 |
| 外观 | 主题和语言 |

## 更改邮箱地址

在**个人资料**下选择**更改邮箱**，输入新地址；开启双重验证时，还需输入身份验证器应用中的验证码或恢复码。Kaeso 会向新地址发送确认链接，并向旧地址发送取消此更改的链接。打开确认链接后更改才会生效。让发起更改的浏览器退出登录、全部退出登录或重置密码也会取消此更改。

确认更改会让您账户的其他所有会话退出登录。打开链接的浏览器保持登录；如果在未登录的地方打开链接，则发起更改的浏览器保持登录。

当某个组织管理您的账户时，您的地址由其身份提供商掌管，**个人资料**不会显示**更改邮箱**。当身份提供商在该组织的已验证域名范围内更改您的地址时，您下次通过它登录时，Kaeso 中的地址也会随之更改（见[受管理的账户](../self-hosting/sign-in.md#受管理的账户)）。

## 更改密码

在**安全**下，**更改密码**会设置新密码，并让您的其他会话退出登录。如果您只使用登录链接或单点登录，就没有密码，可以通过**设置密码**添加一个。

这两种操作之后，您的智能体会继续工作。如果他人可能已将智能体连接到您的账户，例如您因密码泄露而更改密码，请勾选**同时断开我的智能体**；Kaeso 会撤销您授权的所有智能体，之后您再重新连接自己的智能体。

## 开启双重验证

双重验证会在每次使用密码或登录链接登录时要求输入身份验证器应用中的验证码。单点登录不需要验证码，由您的身份提供商进行验证。要求双重验证的组织接受输入了验证码的登录。它也接受通过该组织自己的身份提供商登录，或通过管理您账户的组织的身份提供商登录。

登录链接会先显示它要登录的账户。仅当链接是您自己请求的时才选择**登录**。如果此浏览器已登录另一个账户，登录会在这里替换该会话。

1. 在**安全**下选择**设置**。
2. 用身份验证器应用扫描二维码，或输入设置密钥。
3. 输入应用显示的 6 位验证码，然后选择**开启**。
4. 保存控制台只显示一次的 10 个恢复码：复制它们，或选择**下载 .txt**。每个恢复码可代替应用验证码登录一次。

设置双重验证要求在最近 15 分钟内登录过。**重新生成**会替换恢复码，**关闭**会移除双重验证；两者都需要先输入当前验证码或恢复码。如果身份验证器和恢复码都已丢失，实例管理员可以为您重置双重验证。

每次登录最多接受三个验证码；输错三次后，请重新使用密码或登录链接开始。在登录或确认账户更改时连续输错 10 次后，应用验证码将无法使用。Kaeso 随后会给您发送邮件，此后每再输错 10 次会再发送一封。恢复码仍可让您登录并解除锁定，通过邮件重置密码也可以解除锁定。

## 关联单点登录

只有在您的账户与组织的身份提供商关联后，它才能为您登录。由组织单点登录创建的账户从一开始就已关联。**安全**下的**单点登录**列出您所在的、配置了身份提供商的组织。

1. 使用密码或登录链接登录。
2. 在组织旁选择**关联**。
3. 在身份提供商处登录。您会回到**安全**页面，登录状态与之前相同。

**取消关联**会让该身份提供商不再为您登录，并结束由它登录的会话；与其他安全更改一样，它需要最近登录。组织的审计日志会记录这两种操作，分别为 `user.sso_link` 和 `user.sso_unlink`。

## 退出其他浏览器的登录

**会话**列出您已登录的每个浏览器以及登录方式。**结束会话**会让其中一个退出登录，**全部退出登录**会让除当前浏览器外的所有浏览器退出登录。实例的审计日志会将两者记录为 `user.sessions_revoke`，并注明结束了多少个会话。

会话在 7 天未使用后结束，最长不超过 30 天。

## 管理您的智能体

**智能体**页面顶部显示 MCP 服务器的地址，旁边是 Claude Code、Cursor 和 GitHub Copilot 的标志；点击任一标志即可查看如何将服务器添加到该客户端。下方列出您授权过的每个智能体：名称和模型系列、权限概要、它能访问的组织，以及创建时间和上次使用时间。选择一个智能体即可打开其页面，您可以在那里：

- 重命名它；
- 在与授权页面相同的编辑器中更改其权限，然后选择**保存权限**；
- **撤销**它，使它立即退出登录；
- 查看其**活动**：最近 90 天的每次工具调用，包括工具、目标、结果、时间和 IP 地址。

智能体会一直工作，直到您撤销它、它 90 天未被使用，或您的所有会话都结束，例如您重置密码时。更改密码只有在您选择**同时断开我的智能体**时才会结束它。当它需要自己没有的权限时，会给您一个指向此处其页面的链接，该权限已准备好等您批准（[缺少权限](../api/mcp.md#缺少权限)）。

## 确认敏感操作

某些操作要求在最近 15 分钟内登录过。如果您的登录时间更早，控制台会在执行操作前要求您重新登录。通过单点登录的登录从身份提供商上次验证您的时间算起，这可能远早于它把您送回 Kaeso 的时间。

- 在您的账户中：更改邮箱地址、在没有密码时设置密码以及删除账户。设置或关闭双重验证、重新生成恢复码，以及**单点登录**下的**关联**和**取消关联**，同样需要近期登录。
- 在组织中：[权限](../concepts/rights.md)中标注为需近期登录的权限所对应的操作，例如添加服务商密钥、创建平台密钥或删除日志。
- 对于您的智能体：授予其标有 ⚠ 的敏感权限（[智能体](../concepts/rights.md#敏感权限)）。
- 作为实例管理员：将某人设为实例管理员或取消、删除用户、重置用户的双重验证以及任命组织所有者。计划删除组织、**立即删除**、**更新到 …**、为更新选择**自动**，以及更改账户创建、组织创建或允许的域名，同样需要近期登录。**实例管理员的单点登录**只能通过密码或登录链接的登录来确认。

控制台会要求输入您的密码，或者发送登录链接或设置密码的链接。只有当您的账户这些方式都没有时，例如管理该账户的组织要求单点登录，控制台才会通过您的身份提供商确认。

通过单点登录确认时，控制台会在一个小窗口中打开您的身份提供商，请您在那里重新登录。页面和您输入的内容保持不变，登录后操作会继续进行。只有您本人已关联的身份、经过一次新的登录才能确认，被拒绝时会说明原因。

如果浏览器拦截了该窗口，控制台会在当前标签页前往身份提供商，然后带您回到原页面。通过某个组织的身份提供商确认后，会话会成为来自该组织单点登录的会话。

曾经在没有新登录的情况下作答的身份提供商不会再被提供（[近期登录](../self-hosting/sign-in.md#近期登录)）。

## 通过单点登录登录之后

如果您的地址属于某个启用单点登录的组织的已验证邮箱域名，该组织就管理您的账户，**个人资料**会显示**管理方**及其名称。通过其身份提供商登录是一次完整登录：可以打开您所属的每个组织，各自适用自己的要求。它还允许您更改账户，但更改账户仍需近期登录。管理实例需要再次登录，除非实例管理员已为此选定该组织。

通过不管理您账户的组织的身份提供商登录后，只能打开该组织，并查看您自己的账户。您的地址属于其他域名时就会如此。此时 **API 密钥**只列出您在该组织中的密钥。其他操作都需要再次登录，控制台会要求输入密码或发送登录链接：

- 更改邮箱地址、密码或双重验证；
- 创建组织、退出其他组织或删除账户；
- 打开其他组织或管理实例。

如果管理您账户的组织要求单点登录，您只能通过其身份提供商登录，近期登录也由它确认（见[受管理的账户](../self-hosting/sign-in.md#受管理的账户)）。

如果没有密码，请在**账户** › **安全**中选择**通过邮件发送链接**，或在登录页使用**忘记密码？**，然后通过邮件设置密码。当某个操作需要再次登录而其他方式都不可用时，控制台也会提供同样的链接。

## 选择接收的邮件

Kaeso 会就您的权限使您负责的事项给您发邮件，范围包括实例、您的组织、您的项目及其门户。**通知**只列出您可以接收的邮件，分为**安全**、**个人**、**项目**、**工具**、**组织**和**实例**几个区域。为每封邮件选择发送时间：

| 选项 | 效果 |
| --- | --- |
| 立即 | Kaeso 立即发送 |
| 每日 | 归入在实例时区早上 8:31 发送的摘要，只在有事发生时发送 |
| 关闭 | Kaeso 不发送 |

每周摘要和每月成本报告按各自的计划发送，因此只有开启或关闭两种选择。安全邮件（例如密码已更改，或有新应用可以代表您操作）没有选项：Kaeso 始终立即发送。对于您自己执行的操作，Kaeso 从不给您发邮件。关于同一件事，Kaeso 每天最多发送一封邮件，一小时内超过 20 封的邮件会归入摘要。

| 区域 | 邮件 | 谁可以接收 | 默认 |
| --- | --- | --- | --- |
| 安全 | 账户安全、新应用可以代表您操作 | 您 | 始终 |
| 个人 | 导出已完成 | 发起导出的人（`logs.export`、`audit_log.export`） | 立即 |
| 个人 | 每周摘要 | `usage.view` | 关闭 |
| 项目 | 您的访问权限已变更 | 您 | 立即 |
| 项目 | 预算提醒、已达限额 | `limits.manage`，或设有限额的密钥的所有者 | 立即、每日 |
| 项目 | 您的密钥即将过期、您的密钥已变更 | 密钥的所有者 | 立即 |
| 项目 | 内容记录已变更 | 项目的每个成员 | 每日 |
| 工具 | MCP 服务器需要处理 | `mcp_servers.manage` | 立即 |
| 工具 | 您的连接已过期 | 您，针对您连接了自己账户的服务器 | 立即 |
| 工具 | 门户上的新客户端 | `tools.manage` | 每日 |
| 组织 | 安全设置已变更 | `security.sso.manage` 或 `platform_keys.view` | 立即 |
| 组织 | 所有权和删除 | 所有者 | 始终 |
| 组织 | 成员变动 | `members.invite` | 每日 |
| 组织 | 您的邀请已被接受 | 发出邀请的人 | 立即 |
| 组织 | 服务商密钥需要处理 | `provider_credentials.replace` | 立即 |
| 组织 | 模型变更 | 使用该模型的项目中的 `models.manage` | 每日 |
| 组织 | 每月成本报告 | `costs.org.view` | 开启 |
| 实例 | 更新、实例设置已变更 | 实例管理员 | 立即 |
| 实例 | 新组织和新用户 | 实例管理员 | 每日 |

**发送测试邮件**会向您的地址发送一封，每分钟最多一次。如果实例只把邮件写入日志，页面会说明这一点，并且不提供选项。

要停止某个组织除安全邮件以外的所有邮件，请在**成员身份**下为它关闭**向我发送关于此组织的邮件**。

除安全邮件外，每封邮件末尾都有一个链接，无需登录即可关闭这一类邮件。自带退订按钮的邮件应用使用同一个链接。可在**通知**下重新开启该邮件。

## 选择主题和语言

在**外观**下：

- **主题**可选**系统**、**浅色**或**深色**，保存在当前浏览器中。
- **语言**可选自动、English、Deutsch 或简体中文。自动会跟随浏览器语言；控制台不支持该语言时使用英语。选择会保存到您的账户，因此会同步到其他浏览器，Kaeso 发送的邮件也会使用该语言。

产品名称和模型 ID 在所有语言中保持不变。

## 退出组织或删除账户

**成员身份**下的**退出组织**会让您退出该组织及其项目，并归档您在其中的密钥。组织唯一的所有者要等到其他人也成为所有者后才能退出。

**个人资料**下的**删除账户**会让您退出所有组织，并归档您的所有密钥。历史记录中会显示为已删除的用户。输入您的邮箱地址进行确认。

如果您是某个组织的最后一名所有者，这两项操作都无法进行。请先让其他人成为所有者。
