自己的账户位于侧边栏底部菜单中的**账户**下：

| 页面 | 内容 |
| --- | --- |
| 个人资料 | 头像、名称、邮箱地址和账户 ID；删除账户 |
| 安全 | 密码、双重验证和恢复码 |
| 会话 | 已登录的浏览器 |
| API 密钥 | 自己在所有项目中的密钥（见 [API 密钥](api-keys.md)） |
| 成员身份 | 自己所在的组织及其项目，以及自己的角色；退出组织 |
| 通知 | 接收哪些邮件 |
| 外观 | 主题和语言 |

## 邮箱地址

**更改邮箱**会向新地址发送确认链接，并通知旧地址。打开链接后更改才会生效。此操作需要近期登录。

## 密码

**更改密码**会让其他会话退出登录。如果只使用登录链接或单点登录、尚未设置密码，可以通过**设置密码**添加一个。

## 双重验证

双重验证会在每次使用密码登录时要求输入身份验证器应用中的验证码；登录链接和单点登录不需要。

1. 在**安全**下选择**设置**。
2. 用应用扫描二维码，或输入设置密钥。
3. 输入应用显示的六位验证码，然后选择**开启**。
4. 保存控制台仅显示这一次的 10 个恢复码：复制或**下载 .txt**。每个恢复码可代替验证码登录一次。

**重新生成**会替换恢复码，**关闭**会移除双重验证；两者都需要近期登录。如果身份验证器和恢复码都已丢失，可请实例管理员重置双重验证。

## 会话

**会话**列出所有已登录的浏览器及其登录方式。**结束会话**会让其中一个退出登录，**全部退出登录**会让当前浏览器以外的所有会话退出登录。会话在 7 天未使用后结束，最长 30 天。

## 退出组织和删除账户

**成员身份**下的**退出组织**会让自己退出该组织及其项目，并归档自己在其中的密钥。**个人资料**下的**删除账户**会让自己退出所有组织并归档自己的全部密钥；历史记录中会显示为已删除的用户。需要输入自己的邮箱地址确认，并需近期登录。

如果自己是某个组织的最后一名所有者，这两项操作都无法执行：请先让其他人成为所有者。

## 通知

**预算提醒**和**即将过期的密钥**用于开启或关闭相应邮件。安全邮件（例如密码已更改的通知）始终会发送。

## 主题和语言

在**外观**下：

- **主题**：**系统**、**浅色**或**深色**。保存在当前浏览器中。
- **语言**：**自动**、English、Deutsch 或简体中文。自动会跟随浏览器的语言；控制台不支持该语言时使用英语。所选语言保存在账户中，因此在其他浏览器中同样生效，Kaeso 发送的邮件也会使用该语言。

产品名称和模型 ID 在所有语言中保持不变。
