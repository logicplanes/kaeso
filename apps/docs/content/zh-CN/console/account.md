个人账户位于**设置** › **账户**：在侧边栏底部的菜单中选择**账户**。

| 页面 | 内容 |
| --- | --- |
| 个人资料 | 头像、姓名、邮箱地址、账户 ID，以及删除账户 |
| 安全 | 密码、双重验证和恢复码 |
| 会话 | 当前已登录的位置 |
| API 密钥 | 自己在所有项目中的密钥 |
| 成员资格 | 所在的组织和项目及其中的角色；退出组织 |
| 通知 | 接收哪些邮件 |
| 外观 | 主题和语言 |

## 邮箱地址

**更改邮箱**会向新地址发送确认链接，并通知旧地址。打开链接后更改生效。此操作需要近期登录过。

## 密码和双重验证

**更改密码**会让其他会话退出登录。如果使用登录链接或单点登录（SSO）登录而没有密码，可通过**设置密码**添加一个。

双重验证使用身份验证器应用，适用于密码登录；登录链接无需验证码。**设置**会显示二维码和设置密钥；输入应用中的 6 位验证码，然后选择**开启**。随后会获得 10 个恢复码，每个可代替验证码使用一次，且仅在此时显示；请复制或下载并妥善保存。**重新生成**会替换这些恢复码，**关闭**会移除双重验证。

如果身份验证器和恢复码都已丢失，实例管理员可以重置双重验证。

## 会话

**会话**列出所有已登录的浏览器及其登录方式。**结束会话**让其中一个退出登录；**全部退出登录**让除当前会话外的所有会话退出登录。会话在 7 天未使用后自动结束，最长持续 30 天。

## 退出和删除

**成员资格**下的**退出组织**会将自己从该组织及其项目中移除，并归档自己在其中的密钥。**个人资料**下的**删除账户**会将自己从所有组织中移除，并归档自己的所有密钥；需要输入邮箱地址确认，且需要近期登录过。如果自己是某个组织的最后一位所有者，这两项操作都无法执行：请先将其他人设为所有者。

## 通知

选择是否接收预算提醒和密钥即将过期的警告。安全类邮件（例如密码已更改）始终会发送。

## 主题和语言

在**外观**下：

- **主题**：系统、浅色或深色。保存在当前浏览器中。
- **语言**：自动、English、Deutsch 或 简体中文。“自动”跟随浏览器语言，否则使用英语。所做的选择保存到账户中，因此在其他浏览器中同样生效，Kaeso 发送的邮件也会使用该语言。

在每种语言中，产品名称和模型 ID 都保持原样。
