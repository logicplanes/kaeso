服务商密钥是组织用于 [Kaeso 所调用的模型服务商](../concepts/supported-providers.md)的密钥。Kaeso 使用实例的主密钥加密存储它们，添加后不再显示。应用永远看不到这些密钥，而是使用 [API 密钥](api-keys.md)调用 Kaeso。

## 添加密钥

**服务商**页面列出组织已有密钥的服务商。在组织添加第一个密钥之前，该页面会介绍服务商密钥，并提供**添加服务商密钥**。密钥超过八个时，列表上方的搜索框可按服务商、密钥或项目名称查找。

1. 在**服务商**页面上选择**添加服务商密钥**。
2. **此密钥属于哪个服务商？** 搜索并选择服务商。已有密钥的服务商排在前面，并显示其密钥数量。
3. 粘贴密钥并为其命名，例如 `Production`。对话框会链接到服务商创建密钥的页面，[支持的服务商](../concepts/supported-providers.md)也列出了这些页面。
4. 如果该服务商已有默认密钥，选择新密钥是否成为默认密钥。

对服务商密钥的每种操作都需要相应的权限：

| 操作 | 权限 |
| --- | --- |
| 添加密钥 | **添加服务商密钥** |
| 替换、重命名、分配密钥或将其设为默认 | **更改服务商密钥** |
| 删除密钥 | **删除服务商密钥** |

除删除外，每项操作还需要近期登录。

## 使用 ChatGPT 账户登录

对于 OpenAI，服务商密钥也可以是一个 ChatGPT 账户。其请求随后使用该账户的 ChatGPT 套餐，而不是 OpenAI API 账户，并受套餐限额约束。

> [!WARNING]
> 只使用您自己的账户；共享账户违反 OpenAI 的条款。

1. 在**服务商**页面上选择**添加服务商密钥**，然后选择 **OpenAI**。
2. 选择 **ChatGPT 账户**。如果 OpenAI 已有默认密钥，选择该账户是否成为默认密钥。
3. 为密钥命名并选择**继续使用 ChatGPT**。ChatGPT 会在新标签页中打开：登录并批准 Kaeso。
4. 该标签页随后会转到一个以 `http://127.0.0.1` 开头、无法加载的地址。这是正常的。从地址栏复制该地址。
5. 将其粘贴到**页面地址**中，然后选择**添加账户**。

请在十分钟内由发起者本人完成。Kaeso 会检查该地址，向 OpenAI 登录该账户，并像其他密钥一样加密保存其令牌。Kaeso 会在令牌过期前自动续期。

ChatGPT 账户按 OpenAI 的套餐使用规则处理请求：

- 每个请求都以 OpenAI 不保存的流的形式发送到 `https://api.openai.com/v1/responses`，与实例为 OpenAI 设置的基础 URL 无关。对于需要单个回复的应用，Kaeso 会把流合并为一个回复。
- Kaeso 会省略套餐拒绝的字段：`temperature`、`top_p`、输出和工具调用的限额、`metadata`、`truncation`、用户 ID 以及其他[预览版限制](https://developers.openai.com/siwc/token-sharing-open-source/preview-limitations)。
- 嵌入和 Token 计数需要 API 密钥；Kaeso 会为该账户拒绝这些请求。
- 套餐达到用量上限时，应用会收到 `429`，其中链接到 [ChatGPT 的用量设置](https://chatgpt.com/settings/usage)。
- **检查可用性**只提供该账户在其套餐中列出的模型。

## 选择项目使用的密钥

每个服务商有一个默认密钥，所有未分配密钥的项目都使用它。为服务商添加的第一个密钥会成为默认密钥。要更换默认密钥，在另一个密钥的菜单中选择**设为默认**。

要让部分项目使用其他密钥，在该密钥的菜单中选择**分配给项目**并选择项目。这些项目随后会用该密钥而非默认密钥调用该服务商。每个项目对每个服务商只使用一个密钥。

## 替换、重命名或删除密钥

列表显示每个密钥的名称、最后四个字符、使用它的项目、添加者以及上次使用时间。账户显示其电子邮件地址和产品（例如 **ChatGPT**），而不是最后四个字符。密钥菜单提供以下操作：

| 操作 | 作用 |
| --- | --- |
| 替换 | 为同一个密钥换上新的密钥值，例如在服务商处轮换之后 |
| 重新登录 | 用于账户：重新登录同一个账户，例如在其显示**已退出登录**之后 |
| 管理用量 | 用于 ChatGPT 账户：打开 ChatGPT 的用量设置，账户所有者可在其中查看和限制 Kaeso 的用量 |
| 重命名 | 更改控制台中显示的名称 |
| 删除 | 移除密钥。其项目改回使用默认密钥。对于账户，Kaeso 还会结束其在 OpenAI 的会话 |

当 OpenAI 结束了账户的会话时，例如其所有者在 ChatGPT 中断开了 Kaeso，该账户会显示**已退出登录**。其请求随后会失败，直到拥有**更改服务商密钥**权限的人选择**重新登录**。

删除默认密钥时，该服务商最近添加的另一个密钥会成为默认密钥。如果没有其他密钥，对该服务商的请求将失败。对话框会说明具体情况。

> [!NOTE]
> 项目使用的密钥决定了服务商为其提供哪些模型。添加、替换、分配、删除密钥或将其设为默认，都会把该服务商的模型在所有项目中的[可用性](models-and-aliases.md#可用性)重置为**未检查**。
