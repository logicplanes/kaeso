服务商密钥是 Kaeso 用来调用 OpenAI 和 Anthropic 的密钥。它们属于组织，以部署的主密钥加密保存，添加后不会再次显示。应用从不接触这些密钥；应用使用的是 Kaeso [API 密钥](api-keys.md)。

Kaeso 可调用两个服务商：OpenAI 和 Anthropic。

## 添加密钥

打开**服务商**并选择**添加密钥**，或在尚无密钥的服务商旁选择**连接**。

1. 选择服务商。
2. 粘贴密钥：来自 platform.openai.com 的 OpenAI 密钥以 `sk-` 开头，来自 console.anthropic.com 的 Anthropic 密钥以 `sk-ant-` 开头。为其命名，例如 `Production`。
3. 如果该服务商已有默认密钥，选择是否将此密钥设为默认。

添加密钥需要**添加服务商密钥**权限。替换、重命名、分配密钥以及将密钥设为默认需要**更改服务商密钥**权限，删除密钥需要**删除服务商密钥**权限。添加和更改密钥需要近期登录过。

## 默认密钥和分配

每个服务商有一个**默认**密钥，所有未分配密钥的项目都使用它。为某个服务商添加的第一个密钥成为其默认密钥；在另一个密钥的菜单中选择**设为默认**可更改默认密钥。

要让某些项目使用不同的密钥，请在该密钥的菜单中选择**分配给项目**。这些项目在该服务商上会使用此密钥，而不是默认密钥。每个项目对每个服务商使用一个密钥。

## 更改或移除密钥

| 操作 | 作用 |
| --- | --- |
| 替换 | 为同一密钥粘贴新的密钥值，例如在服务商处轮换密钥之后 |
| 重命名 | 更改控制台中显示的名称 |
| 删除 | 移除密钥；其项目重新使用默认密钥。删除默认密钥后，该服务商最近添加的另一个密钥会成为默认密钥；如果没有其他密钥，对该服务商的请求将失败。对话框会说明适用哪种情况 |
