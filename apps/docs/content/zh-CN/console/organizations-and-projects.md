组织包含成员、服务商密钥和项目。项目包含模型目录、API 密钥、服务账号、限额和请求日志。每个人以组织角色加入组织，并以项目角色加入其中的各个项目。

## 创建组织

打开侧边栏底部的菜单，选择**创建组织**。您会成为新组织的所有者，新组织中还没有项目。谁可以创建组织由实例决定（见[实例设置](instance-administration.md#更改实例设置)）。

同一菜单列出您所在的组织，并可在它们之间切换。打开 Kaeso 或切换到另一个组织时，会显示该组织的**概览**；可在其中或侧边栏中打开项目。

## 查看用量

组织的**概览**是它的主页。最上方是 Kaeso 正在运行的版本，接着显示最近 7、14 或 30 天的请求、Token、缓存命中和失败请求；拥有查看费用的权限时，还显示本月按项目划分的支出。下方列出各项目今天的请求、成员、提供商密钥、MCP 服务器、最近的更改，以及目录中最新的模型。点击任一总数，会在**分析**中打开该指标。

**分析**显示所选时间段内的请求、Token、费用、错误和工具调用，时间段从今天到全部时间，并将每项总数与之前的同等时间段比较，但今天（尚未结束）和全部时间除外。总数位于最上方，所选的一项会与之前的时间段对比绘制，之前的时间段以虚线显示：开启请求日志时，一两天的时间段按小时绘制；一个季度以内按 UTC 日，两年以内按周，更长则按月。图表下方是该总数中占比最高的五个项目和模型，各带占比和变化；**可靠性**显示失败请求、失败类型和最慢的小时；**效率**显示缓存命中和每个请求的 Token；**支出**显示本月预测和按项目划分的费用。失败类型和最慢的小时来自请求日志，适用于 62 天以内的时间段。仍在进行中的日、周或月以虚线或较浅颜色绘制，其提示显示“截至目前”。**项目**、**模型**和**成员**按行列出该时间段，包括占比、增长与下降、错误率、Token、缓存命中和费用。查看用量需要**查看组织用量**权限，查看费用需要**查看组织费用**权限。

包含媒体请求的明细有一个**媒体**列：生成的图片、朗读的字符数、生成或转写的音频时长，以及生成的视频及其时长。某组请求都没有已知价格时，费用显示为**未知**；只有部分请求没有时，费用旁会显示有多少个请求的费用未知。

项目的**概览**显示最近几天的活动、实时到达的最新请求、限额及其使用情况、按用量排列的模型、按最近使用排列的密钥、成员以及最近的更改。项目的**分析**为单个项目显示与组织相同的内容，包括**模型**、**密钥**和**成员**，预测旁显示项目的支出预算，页面底部按时间、模型、密钥、成员或路由划分。点击列表中的一行，会打开该时间段内对应模型、密钥或失败类型的请求日志。

路由由应用的格式、Kaeso 调用服务商所用的格式和服务商组成。其明细有**缓存命中**列：输入中从提示缓存读取的占比。同一个模型可能通过一条路由命中缓存，通过另一条却从不命中，因此**按路由**能显示缓存在哪里失效。Kaeso 开始记录路由之前的请求显示为**未记录路由**。

## 更改组织设置

在侧边栏底部的菜单中打开**组织设置**，其中包含以下页面：

| 页面 | 内容 |
| --- | --- |
| 常规 | 头像、名称和组织 ID，**转让所有权**，以及删除组织 |
| 成员 | 成员、邀请和角色（见[成员和角色](members-and-roles.md)） |
| 安全 | 单点登录、登录要求、密钥最长有效期以及成员的智能体 |
| 平台密钥 | 供管理组织的脚本使用的密钥（见[平台密钥](api-keys.md#平台密钥)） |
| 日志记录 | 内容日志、保留期、存储和日志删除（见[请求日志](request-logs.md#保留期)） |
| 审计日志 | 组织中的每一项变更（见[审计日志](#查看审计日志)） |

头像可以是 PNG、JPEG 或 WebP 图片，控制台会将其裁剪为正方形。

## 单点登录（SSO）

单点登录让成员通过您的 OpenID Connect 身份提供商登录。先在身份提供商处为 Kaeso 创建一个应用。然后在**安全**下选择**连接身份提供商**，并完成五个步骤：

1. **您的身份提供商在哪里？** 此步骤会显示**重定向 URL**，请在应用中将其注册为登录回调地址。输入该应用的颁发者 URL，例如 `https://login.example.com`。
2. **用哪个应用登录？** 输入其客户端 ID 和客户端密钥。
3. **哪些邮箱域名通过它登录？** 登录页会把使用这些域名邮箱的人员引导到您的身份提供商。国际化域名两种写法均可，如 `bücher.example` 或 `xn--bcher-kva.example`。
4. **未受邀的人员能否加入？** 选择**仅限受邀**，或选择首次使用 Kaeso 的人员加入时的角色。该角色不能是所有者。
5. **登录页如何提供它？** 在**按钮名称**中填写名称，例如填写 `Acme ID` 时按钮显示“使用 Acme ID 继续”。留空则显示“使用 SSO 继续”。开启**无需点击即开始**后，登录页会直接前往您的身份提供商，不显示其按钮。这发生在有人输入您已验证域名的地址，且该身份提供商是其唯一登录方式时。**要求已验证的地址**会拒绝未将地址标记为已验证的令牌；仅当身份提供商从不发送 `email_verified` 时才关闭。

连接后，页面会显示**重定向 URL**：在身份提供商处将其注册为登录回调地址。若要让成员从内网或书签进入单点登录，请链接到实例的登录页，例如 `https://kaeso.example.com/sign-in`。它会先询问地址（[登录页](../self-hosting/sign-in.md#登录页)）。

### 验证邮箱域名

单点登录只为已验证域名下的地址登录和加入组织，因此任何组织都无法占用不属于它的域名。**安全**页面会显示每个域名是**已验证**还是**未验证**，以及未验证的域名所需的 TXT 记录。请在您的 DNS 服务商处添加该记录，然后选择域名旁的**验证**：

```text
_kaeso-verify.acme.example  TXT  "kaeso-verify=Qm9ZtX3c8L1aV7pK2rN5wE0yH4uJ6sD9fG1bC3xT8eA"
```

DNS 更改可能需要一些时间才能生效，可稍后再次选择**验证**。公共邮箱域名（例如 `gmail.com`）无法添加，其他组织已验证的域名也无法添加。对于公共 DNS 无法解析的域名，运维人员可在服务器上运行 `kaeso sso verify-domain acme.example` 进行验证。

**编辑单点登录**可更改连接。只要颁发者和客户端 ID 不变，客户端密钥留空即保留已存储的值。更换颁发者或客户端 ID 会结束先前身份提供商登录的会话。**断开连接**会移除连接并结束由它登录的会话，成员将重新使用密码或登录链接登录。

只有当账户所有者在**账户**中将其与您的身份提供商关联后（见[关联单点登录](account.md#关联单点登录)），单点登录才会为已有的 Kaeso 账户登录。该账户还必须属于此组织：请先邀请此人，对方用其他方式登录后接受邀请。更改单点登录需要近期登录过的控制台会话，平台密钥无法更改。全部规则以及仅使用单点登录运行实例的方法，见[登录和单点登录](../self-hosting/sign-in.md)。

成员用密码或登录链接确认近期登录。只有没有其他方式的账户才通过单点登录确认，例如开启**要求单点登录**时该组织管理的账户。这只有在身份提供商按要求重新登录用户，并在 ID 令牌中发送 `auth_time` 时才可行。

如果一次确认返回时没有新的登录，**安全**页面会显示**近期登录**，并且不再提供该身份提供商用于确认。如果开启了**要求单点登录**，该组织管理的账户此后完全无法确认（[近期登录](../self-hosting/sign-in.md#近期登录)）。

连接后，该组织即管理其已验证域名下的账户：通过其身份提供商登录可以打开这些账户能打开的一切，实例管理除外（见[受管理的账户](../self-hosting/sign-in.md#受管理的账户)）。

## 要求单点登录或双重验证

在**安全**下，可以收紧成员进入组织的方式：

| 设置 | 作用 |
| --- | --- |
| 要求单点登录 | 其已验证域名下的账户只能通过 SSO 登录；访客保留自己的登录方式。其管理的账户在整个实例上都不能用密码或登录链接登录，其他会话也会结束。需要已连接身份提供商 |
| 要求双重验证 | 成员登录时（使用密码或登录链接）需要输入身份验证器中的验证码。通过单点登录登录也可以，无论来自组织自己的身份提供商，还是管理该成员账户的组织的身份提供商 |
| 密钥最长有效期 | 新密钥的最长有效天数，或**不限制**。现有密钥保留原有过期时间，项目可以设置更短的上限 |

如果开启一项您自己尚未满足的要求，该组织对您也会关闭，直到您通过身份提供商登录或设置好双重验证。控制台会在保存前请您确认。要求单点登录会保留您自己的会话，因此[服务器上生成的登录链接](../self-hosting/sign-in.md#重新登录)绝不会是您重新进入的唯一途径。断开身份提供商也会关闭**要求单点登录**。

## 允许成员的智能体

成员可以连接 Claude Code 或 Codex 等智能体，让它们通过 [MCP 服务器](../api/mcp.md)代表自己行事。在**安全**下，**智能体**部分包含组织的智能体策略。它决定这些智能体能否在组织中行事，以及能做到什么程度：

| 设置 | 作用 |
| --- | --- |
| 允许成员的智能体 | 默认开启。关闭后，每个智能体在下一次请求时在此组织中收到 403，在其他地方照常工作 |
| 智能体最多可做的事 | **观察者**、**构建者**、**运维者**或**完全访问**，每一级都包含之前各级。默认是**完全访问**。无论成员授予了什么，智能体在此都不会获得更多权限 |

更改该策略需要**更改成员角色**和控制台会话；任何智能体都无法更改。[智能体](../concepts/rights.md#预设)列出每个预设包含的权限。

其下方的**有访问权限的智能体**列出可以在组织中行事的智能体，包括其成员、模型系列，以及创建时间和上次使用时间。查看它们需要**查看成员**。**关闭访问**会对某个智能体关闭组织，需要**更改成员角色**。该智能体在其成员的其他组织中照常工作，其成员也可以重新为它开放此组织。

## 删除组织

在**常规**下选择**删除组织**，并输入组织名称确认。这需要**删除组织**权限（所有者拥有），并且实例必须允许删除组织。

1. 组织的所有 API 密钥立即失效，Kaeso 会通过邮件通知成员。
2. 在宽限期内（默认 7 天，实例可另行设置），组织为只读状态，每个页面都会显示横幅提示。所有者仍可选择**恢复组织**。
3. 宽限期结束后，Kaeso 会永久删除其项目、密钥、服务商密钥、设置、用量和日志。宽限期一结束，即使 Kaeso 尚未删除完毕，该组织也无法再恢复。

## 查看审计日志

**组织设置**中的**审计日志**记录组织中的每一项变更。项目侧边栏中的**审计日志**记录该项目中的每一项变更。

每条记录显示时间、操作者、操作和目标。可按操作者、操作、目标 ID 和日期筛选。选择一条记录可查看 IP 地址、用户代理、请求 ID、权限变更以及变更前后的值。

智能体所做的更改显示其所代表成员的头像，右下角带有一个小机器人徽标。将鼠标悬停其上，可以看到成员、智能体及其模型系列。**智能体**筛选只显示智能体所做的更改，Platform API 在 `actor.agent` 中标明该智能体（[活动和审计](../api/mcp.md#活动和审计)）。

| 操作 | 权限 |
| --- | --- |
| 查看组织的审计日志 | **查看审计日志** |
| 按当前筛选条件导出为 JSON Lines | **导出审计日志** |
| 查看项目的审计日志 | **查看项目审计日志** |

## 创建项目

在**项目**中选择**创建项目**并填写名称。您会成为该项目的管理员。创建项目需要**创建项目**权限。

**已归档**列出已归档的项目，**全部**列出所有项目。搜索可按名称查找项目；能查看组织用量的人可看到每个项目最近 30 天的请求数。

组织中的所有项目地位相同。加入组织不会让人加入任何项目：邀请会指定要加入的项目，其他人可在项目的**成员**页面中添加。

## 更改项目设置

项目的**设置**页面包含以下设置：

| 设置 | 作用 |
| --- | --- |
| 图片、项目名称 | 显示在侧边栏和请求日志中 |
| 项目 ID | Platform API 使用的 ID |
| 密钥最长有效期 | **沿用组织的上限**，或为本项目的新密钥设置更短的上限 |
| 内容日志 | 是否随日志条目保留请求和回复正文。组织关闭时，项目无法开启 |
| 保留媒体 | 已记录的内容是否保留其中的图片、音频和文件（见[请求日志](request-logs.md#请求和回复中的媒体)）。组织不保留时，项目无法开启 |
| 归档项目 | 永久归档项目及其密钥和服务账号。其密钥立即失效 |

Kaeso 只会归档项目，不会删除，因此其用量和日志会保留。任何项目都可以归档。
