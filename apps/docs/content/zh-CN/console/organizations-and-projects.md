**组织**包含成员、服务商密钥和项目。**项目**包含模型目录、API 密钥、服务账号、限额和请求日志。每个人以组织角色属于一个组织，并以项目角色属于其中的部分项目（见[成员和角色](members-and-roles.md)）。

## 组织

侧边栏底部菜单中的**创建组织**会创建新组织，由自己担任所有者，并附带一个默认项目。谁可以创建组织由部署决定（见[实例设置](instance-administration.md#设置)）。同一菜单列出自己所在的组织，并可在它们之间切换。

### 概览

组织的**概览**显示所选时间段（从今天到全部时间）的请求、Token、费用和错误，各项目费用，以及按项目、模型或成员划分的用量明细。查看用量需要**查看组织用量**权限，查看费用需要**查看组织费用**权限。

### 设置

侧边栏底部菜单中的**组织设置**包含以下页面：

| 页面 | 内容 |
| --- | --- |
| 常规 | 头像、名称和组织 ID；**转让所有权**；删除组织 |
| 成员 | 成员、邀请和角色（见[成员和角色](members-and-roles.md)） |
| 安全 | 单点登录、要求单点登录和双重验证、密钥最长有效期 |
| 平台密钥 | 供管理组织的脚本使用的密钥（见[平台密钥](api-keys.md#平台密钥)） |
| 日志记录 | 内容日志、保留期、存储和日志删除（见[请求日志](request-logs.md#保留期)） |
| 审计日志 | 组织中的每一项变更（见[审计日志](#审计日志)） |

图片可以是 PNG、JPEG 或 WebP，会被裁剪为正方形。

### 单点登录（SSO）

在**安全**下，**连接身份提供商**可让成员通过自己的 OpenID Connect 提供商登录。先在提供商处为 Kaeso 创建一个应用，然后完成五个步骤：

1. **您的身份提供商在哪里？** 该应用的 Issuer URL，例如 `https://login.example.com`。
2. **用哪个应用登录？** 其客户端 ID 和客户端密钥。
3. **哪些邮箱域名通过它登录？** 使用这些域名邮箱的人员会被引导到该提供商。国际化域名两种写法均可，如 `bücher.example` 或 `xn--bcher-kva.example`。
4. **未受邀的人员能否加入？** 选择**仅限受邀**，或选择首次使用 Kaeso 的人员加入时的角色。不能选择所有者。
5. **登录页如何提供它？** **按钮名称**，例如填写 `Acme ID` 时按钮显示**使用 Acme ID 继续**；留空则显示**使用 SSO 继续**。**无需点击即开始**会在登录页只提供该提供商时直接跳转过去，但刚退出登录或提供商拒绝登录后除外。

连接后，页面会显示：

- **重定向 URL**，需在提供商处注册为登录回调地址；
- **登录链接**，打开带有该提供商按钮的登录页，无需输入邮箱地址；可分享给成员，例如放在内网上。

**编辑单点登录**可更改连接；客户端密钥留空则保留已存储的值。**断开连接**会移除连接，成员将重新使用密码或登录链接登录。

已有的 Kaeso 账户只能通过单点登录进入其已加入的组织：先邀请该账户，对方用其他方式登录后接受邀请。全部规则以及仅使用单点登录运行部署的方法，见[登录和单点登录](../self-hosting/sign-in.md)。

### 登录要求

同样在**安全**下：

| 设置 | 作用 |
| --- | --- |
| 要求单点登录 | 成员只能通过身份提供商进入该组织；其他会话对其所在的其他组织仍然有效。需要已连接身份提供商 |
| 要求双重验证 | 使用密码登录的成员必须启用双重验证。登录链接和单点登录不受影响 |
| 密钥最长有效期 | 新密钥的最长有效天数，或**不限制**。现有密钥保留原有过期时间，项目可以设置更短的上限 |

如果自己并非通过身份提供商登录，或尚未启用双重验证，开启相应要求后，自己在完成之前也无法进入该组织；控制台会在保存前提示。

### 删除组织

如果部署允许，拥有**删除组织**权限的人（默认为所有者）在**常规**下选择**删除组织**，并输入组织名称确认。

- 组织的所有 API 密钥立即失效，成员会收到邮件通知。
- 在宽限期内（默认 7 天，部署可另行设置），组织为只读状态，每个页面都会显示横幅提示，所有者可以通过**恢复组织**将其恢复。
- 宽限期结束后，其项目、密钥、服务商密钥、设置、用量和日志会被永久删除。

### 审计日志

组织设置中的**审计日志**记录组织中的每一项变更；项目侧边栏中的**审计日志**记录该项目中的每一项变更。每条记录显示时间、操作者、操作和目标；可按操作者、操作、目标 ID 和日期筛选。打开一条记录可查看 IP 地址、用户代理、请求 ID、权限变更以及变更前后的值。

| 操作 | 权限 |
| --- | --- |
| 查看组织的审计日志 | **查看审计日志** |
| 按当前筛选条件**导出**为 JSON Lines | **导出审计日志** |
| 查看项目的审计日志 | **查看项目审计日志** |

## 项目

**项目**列出组织的项目，已归档的项目在**全部**下。**创建项目**需要填写名称，创建者成为该项目的管理员；创建项目需要**创建项目**权限。

**默认项目**是每个成员都会加入、新成员首先进入的项目。在另一个项目的菜单中选择**设为默认**即可更换；原默认项目仍是普通项目，成员保持不变。此操作需要**编辑组织**权限。

### 概览

项目的**概览**显示某一时间段的请求、Token、费用和错误，按时间、模型、密钥或成员划分的明细，项目限额及其使用情况，以及最近的错误。

### 设置

| 设置 | 作用 |
| --- | --- |
| 图片、项目名称 | 显示在侧边栏和请求日志中 |
| 项目 ID | Platform API 使用的 ID |
| 密钥最长有效期 | **沿用组织的上限**，或为本项目的新密钥设置更短的上限 |
| 内容日志 | 是否随日志条目保留请求和回复；组织关闭时，项目无法开启 |
| 归档项目 | 永久归档项目及其密钥和服务账号；其密钥立即失效 |

项目只会归档，不会删除，因此其用量和日志会保留。默认项目无法归档；请先将另一个项目设为默认。
