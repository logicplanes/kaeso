**组织**包含成员、服务商密钥和项目。**项目**包含模型目录、API 密钥、限额和请求日志。人员属于一个组织及其中的部分项目，在每处各有一个角色。

## 组织

在侧边栏底部的菜单中选择**创建组织**即可创建组织。创建者成为其所有者，组织创建时自带一个默认项目。是否可以创建组织由部署决定；请参阅[实例管理](instance-administration.md#设置)。

同一菜单列出自己所在的组织，并可在其间切换。

### 概览

组织的**概览**显示所选时间段内的请求、Token、费用和错误，时间段可从今天到全部时间，还显示按项目划分的费用，以及按项目、模型或成员的明细。查看用量需要**查看组织用量**权限，查看费用需要**查看组织费用**权限。

### 设置

在侧边栏底部菜单的**组织设置**下，组织有以下页面：

| 页面 | 内容 |
| --- | --- |
| 常规 | 头像、名称和 ID，转让所有权，删除组织 |
| 成员 | 成员、邀请和角色；请参阅[成员和角色](members-and-roles.md) |
| 安全 | 单点登录（SSO）、强制单点登录和强制双重验证、密钥最长有效期 |
| 平台密钥 | 供管理组织的脚本使用的密钥；请参阅 [API 密钥](api-keys.md#平台密钥) |
| 日志记录 | 内容日志、保留期、存储和日志删除；请参阅[请求日志](request-logs.md#保留期) |
| 审计日志 | 组织中的每项更改，以及更改者和更改时间；可导出为 JSON Lines |

### 单点登录（SSO）

在**安全**下，选择**连接身份提供商**，即可通过自己的 OpenID Connect 提供商让人员登录。输入 Issuer URL、在该提供商处注册的应用的客户端 ID 和客户端密钥，以及使用该方式登录的邮箱域名。选择是否允许人员无需邀请即可加入，以及以何种角色加入；这只适用于新加入 Kaeso 的人员，已有账户只有在成为组织成员之后才能通过单点登录登录。国际化域名可以用任一形式输入，例如 `bücher.example` 或 `xn--bcher-kva.example`。页面会显示需要在提供商处注册的重定向 URL。

连接后，**要求单点登录**会使其成为进入组织的唯一方式。**要求双重验证**适用于密码登录，不适用于登录链接或单点登录。

### 删除组织

如果部署允许，所有者可在**常规** › **删除组织**下删除组织，需输入组织名称确认；此操作需要近期登录过，成员会收到邮件通知。组织的密钥立即停止工作；组织在宽限期内保持只读且可恢复，宽限期默认 7 天，之后将被永久删除。在此之前，每个页面都会显示一条横幅，**恢复组织**可将其恢复。

## 项目

**项目**列出组织的项目；已归档的项目位于**全部**下。**创建项目**需要填写名称；创建者成为项目的管理员。创建项目需要**创建项目**权限。

**默认项目**是每位成员都会加入、新成员首先进入的项目。要更改默认项目，请在另一个项目的菜单中选择**设为默认**；此操作需要**编辑组织**权限。

### 概览

项目的**概览**显示某一时间段内的请求、Token、费用和错误，按时间、模型、密钥或成员的明细，其限额及已用量，以及近期错误。

### 设置

| 设置 | 作用 |
| --- | --- |
| 图片、名称 | 显示在侧边栏和请求日志中 |
| 密钥有效期 | **沿用组织的上限**，或为此项目的新密钥设置更短的最长期限 |
| 内容日志 | 是否随日志条目保存请求和回复；组织关闭此项时无法开启 |
| 归档项目 | 永久归档项目及其密钥和服务账号，其密钥随之停止工作；默认项目无法归档 |

项目只会被归档，从不被删除，因此其用量和日志都会保留。

### 审计日志

项目的**审计日志**列出项目中的每项更改，以及更改者和更改时间，可按操作、操作者和日期筛选。查看需要**查看项目审计日志**权限。
