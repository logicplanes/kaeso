**试验场**可将一个提示词同时发送给项目中最多四个模型，并将它们的回复并排显示。每一列都是独立的对话。使用试验场需要**使用试验场**权限，项目管理员和开发者拥有此权限。

试验场中的请求是真实请求。它们使用项目的服务商密钥、自己的模型访问权限，以及自己和项目的限额；费用计入项目，并以来源**试验场**出现在[请求日志](request-logs.md)中。由于不使用密钥，密钥限额不适用。

## 比较模型

1. 为第一列选择模型，再通过**添加列**添加更多列。如果某个模型的服务商在本项目中没有密钥，则无法选择该模型。
2. 向所有模型发送提示词。
3. 每条回复会显示首个 Token 的耗时、总耗时、Token 数和费用。

**清除**会清空所有列的对话。

模型和参数是页面地址的一部分，因此链接会打开同样的比较。尚未发送的提示词会保留在浏览器中；对话不会保存。

## 参数

**参数**设置每一列随请求发送的内容：

| 参数 | 作用 |
| --- | --- |
| 系统指令 | 在对话之前发送的指令 |
| 温度、Top P | 采样参数，只发送给支持温度参数的模型 |
| 最大输出 Token 数 | 回复的最大长度 |
| 推理强度 | 推理模型的思考程度，从**无**到**最大** |
| 推理摘要 | 是否对推理模型的思考进行摘要：**自动**、**简洁**、**详细**或**关闭** |

**恢复默认值**会清除除系统指令以外的所有参数。
