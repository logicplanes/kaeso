**试验场**将一个提示词发送给项目中的一个或多个模型，并将其回复并排显示，最多同时四个。每一列都是独立的对话。

试验场的请求是真实请求。它们使用项目的服务商密钥、自己的模型访问设置，以及自己和项目的限额与预算。这些请求计入项目费用，并以来源**试验场**出现在请求日志中。由于不使用密钥，密钥的限额不适用。

## 使用方法

1. 为第一列选择一个模型；**添加列**可添加更多列。
2. 输入提示词并发送。
3. 每条回复会显示首个 Token 的耗时、总耗时、Token 数和费用。

**清除**会清空所有列的对话。

如果某个模型的服务商在此项目中没有密钥，则无法选择该模型。

## 参数

**参数**设置随每一列发送的内容：

| 参数 | 作用 |
| --- | --- |
| 系统指令 | 在对话之前发送的指令 |
| 温度、Top P | 采样参数，仅发送给接受温度参数的模型 |
| 最大输出 Token 数 | 回复的最大长度 |
| 推理强度 | 推理模型的思考程度，从无到最大 |
| 推理摘要 | 是否对推理模型的思考进行摘要：自动、简洁、详细或关闭 |

**恢复默认值**会清除这些参数。

模型和参数是页面地址的一部分，因此打开该页面的链接会显示相同的比较。尚未发送的提示词保存在浏览器中；对话不会被保存。

使用试验场需要**使用试验场**权限，项目管理员和开发者拥有此权限。
