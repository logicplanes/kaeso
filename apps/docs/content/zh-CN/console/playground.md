**试验场**会把一个提示词同时发送给项目中最多四个模型，并排显示它们的回复。每一列都是独立的对话。使用试验场需要**使用试验场**权限，项目管理员和开发者拥有该权限。

它会列出项目可以调用的每一类模型，每一列都按其模型的类别呈现：文本、图片、语音、音效、音乐、转写或视频。嵌入、重排序和实时模型不会列出，只做决策的模型也不会列出。

## 比较模型

1. 为第一列选择一个模型，并用**添加列**添加更多列。可按名称、ID 或服务商搜索，也可将列表限定为一个服务商；模型按服务商分组，最近选择的模型排在最前。如果某个模型的服务商在本项目中没有密钥，或该模型因服务商不向项目的密钥提供而被标记为[不可用](models-and-aliases.md)，则无法选择该模型。标记为**需要 API 密钥**的模型同样无法选择：项目为其服务商使用的密钥是一个账户，例如 [ChatGPT 账户](provider-keys.md#使用-chatgpt-账户登录)，它无法生成图片、语音或转写。
2. 向所有模型发送一个提示词。所选模型能读取文件时，可以用附件按钮添加，按钮名称会说明模型接受的类型，例如**添加图片**；也可以把文件拖到或粘贴到提示词框中。每个模型只收到它能读取的文件：文本模型收到图片和 PDF，可编辑图片的图片模型收到图片，转写模型收到音频。文本模型在之后的每一轮也会再次收到这些文件。
3. 查看回复。回复到达时，列会跟随显示，直到您向上滚动；滚回末尾后会继续跟随。每条回复都会显示首个 Token 的耗时、总耗时、Token 数和费用。失败的回复会在其所在列显示原因；被模型截断的回复会说明原因，例如**达到输出限额后停止**。**重试**会再次发送这一轮。

**清除**会清空每一列的对话；通知中的**撤销**可将其恢复。

页面地址包含所选模型和参数，因此打开链接即可看到同样的比较。尚未发送的提示词会保留在您的浏览器中。只要控制台在此标签页中保持打开，对话就会保留，即使您访问其他页面后再返回也是如此。控制台从不存储对话，因此重新加载或关闭标签页会结束对话，浏览器会先询问您。

## 试用媒体模型

同一个提示词会发送到每一列，因此文本模型和图片模型可以并排回答它。每个媒体列在回复的位置显示其模型生成的内容：

| 类别 | 您发送 | 您得到 |
| --- | --- | --- |
| 图片 | 一个提示词；模型能编辑图片时，还可附上要修改的图片 | 生成的图片，每张都可**下载** |
| 语音 | 要朗读的文本 | 带**下载**的音频播放器 |
| 音效、音乐 | 一段描述 | 带**下载**的音频播放器 |
| 转写 | 一个音频文件（附加或用**录制音频**录制）和可选的说明 | 转写文本 |
| 视频 | 一个提示词 | 任务进度和**取消**，完成后是带**下载**的视频 |

视频任务需要几分钟。试验场每隔几秒询问一次任务状态，任务运行越久，询问间隔越长。**取消**或**停止**会在服务商处取消任务。只有您能看到自己在试验场中启动的视频。

媒体回复会显示耗时和费用。模型对其生成的内容没有价格时，费用显示为**未知**，例如浏览器未注明时长的录音。

## 设置参数

**参数**设置每一列发送的内容：

| 参数 | 作用 |
| --- | --- |
| 系统指令 | 在对话之前发送的指令 |
| 温度、Top P | 采样参数，只发送给支持温度参数的模型 |
| 最大输出 Token 数 | 回复的最大长度 |
| 推理强度 | 推理模型的思考程度，从**无**到**最大** |
| 推理摘要 | 是否对推理模型的思考过程进行摘要：**自动**、**简洁**、**详细**或**关闭** |

对于媒体模型，**参数**只显示所选模型接受的设置：

| 参数 | 作用 |
| --- | --- |
| 图片尺寸、每个提示词的图片数、图片质量 | 图片模型生成图片的尺寸、数量和质量 |
| 声音 | 语音模型朗读时使用的声音 |
| 时长（秒） | 音效或音乐的长度 |
| 转写 | **按原语言**，或对可翻译的转写模型选择**译成英文** |

**恢复默认值**会清除除系统指令以外的所有参数。

## 试验场请求的费用

试验场中的请求是真实请求，费用计入项目。它们使用项目的服务商密钥、您的模型访问权限，以及您和项目的限额。密钥限额不适用，因为没有使用密钥。[请求日志](request-logs.md)会以来源**试验场**列出这些请求。
