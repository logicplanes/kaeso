**试验场**会把一个提示词同时发送给项目中最多四个模型，并排显示它们的回复。每一列都是独立的对话。使用试验场需要**使用试验场**权限，项目管理员和开发者拥有该权限。

## 比较模型

1. 为第一列选择一个模型，并用**添加列**添加更多列。可按名称、ID 或服务商搜索，也可将列表限定为一个服务商；模型按服务商分组，最近选择的模型排在最前。如果某个模型的服务商在本项目中没有密钥，或该模型因服务商不向项目的密钥提供而被标记为[不可用](models-and-aliases.md)，则无法选择该模型。
2. 向所有模型发送一个提示词。
3. 查看回复。每条回复都会显示首个 Token 的耗时、总耗时、Token 数和费用。失败的回复会在其所在列显示原因；被模型截断的回复会说明原因，例如**达到输出限额后停止**。**重试**会再次发送这一轮。

**清除**会清空每一列的对话；通知中的**撤销**可将其恢复。

页面地址包含所选模型和参数，因此打开链接即可看到同样的比较。尚未发送的提示词会保留在您的浏览器中。只要控制台在此标签页中保持打开，对话就会保留，即使您访问其他页面后再返回也是如此。控制台从不存储对话，因此重新加载或关闭标签页会结束对话，浏览器会先询问您。

## 设置参数

**参数**设置每一列发送的内容：

| 参数 | 作用 |
| --- | --- |
| 系统指令 | 在对话之前发送的指令 |
| 温度、Top P | 采样参数，只发送给支持温度参数的模型 |
| 最大输出 Token 数 | 回复的最大长度 |
| 推理强度 | 推理模型的思考程度，从**无**到**最大** |
| 推理摘要 | 是否对推理模型的思考过程进行摘要：**自动**、**简洁**、**详细**或**关闭** |

**恢复默认值**会清除除系统指令以外的所有参数。

## 试验场请求的费用

试验场中的请求是真实请求，费用计入项目。它们使用项目的服务商密钥、您的模型访问权限，以及您和项目的限额。密钥限额不适用，因为没有使用密钥。[请求日志](request-logs.md)会以来源**试验场**列出这些请求。
