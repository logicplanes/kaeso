Kaeso 记录每个模型请求：模型、服务商、状态、Token、费用、耗时、密钥以及发送者。开启内容日志后，还会保留应用发送和收到的内容。请求结束后几秒内，对应条目就会出现。

> [!NOTE]
> 实例可以在关闭请求日志的情况下运行（[选择请求日志的保存方式](../self-hosting/installation.md#选择请求日志的保存方式)）。这时其项目没有**请求日志**页面，**日志记录**会说明日志已关闭。用量和费用的计算方式不变。

## 查找请求

打开项目的**请求日志**页面。它按时间倒序列出最近 1 小时、24 小时、7 天、30 天或自定义范围内的请求。

- **添加筛选**可按密钥、成员、模型、服务商、状态、错误类型、是否流式以及来源（API 或试验场）缩小列表范围。**仅失败**只显示错误。
- **应用格式**和**服务商格式**可将列表缩小到一条路由，例如从 OpenAI Responses 到 Anthropic Messages。不同路由的缓存、开销和错误往往不同。
- **实时**会在新请求到达时将其加入列表。向下滚动后，会有一个按钮显示新请求的数量。
- 显示选项用于选择列和密度。
- **按 ID 打开请求**可根据应用收到的 `kaeso-request-id` 响应头找到对应请求。

查看日志需要**查看请求日志**权限。

## 查找工具调用

页面顶部的**工具**会改为列出 MCP 客户端通过项目 MCP 门户发起的调用：工具、调用成功、失败还是被拒绝、调用方、客户端以及服务器耗时。被拒绝的调用会说明原因，例如工具已关闭、等待审核、超出调用方的访问权限，或达到工具调用速率。开启内容记录时，调用还会保留其参数和回答，仅持有**查看提示词和输出**权限时可见。

工具调用使用同一工具栏：**添加筛选**可按密钥、成员、MCP 服务器、工具、状态和错误类型缩小范围，**实时**会在新调用到达时将其加入，**按 ID 打开工具调用**可找到单个调用。在**模型**和**工具**之间切换时，会保留时间范围、两者的筛选条件以及**实时**。

## 查看请求

选择一个请求即可打开：

| 标签页 | 内容 |
| --- | --- |
| 概览 | 结果、路由、发送者、耗时、流式传输情况和用量 |
| 请求 | 应用发送的内容 |
| 回复 | 应用收到的内容 |
| 原始数据 | Platform API 返回的日志条目原文 |

耗时会把 Kaeso 自身的工作与应用和服务商的时间分开。**请求上传**是应用发送请求体所用的时间，从 Kaeso 开始读取到全部到达为止；它随请求体的大小和应用的网络连接增长，与 Kaeso 的工作无关。**Kaeso 开销**是 Kaeso 调用服务商之前自身花费的时间，不含上传：校验密钥、解码、转换格式和检查限额。对于流式回复，**流处理**是 Kaeso 为应用转换服务商事件所花的时间，不含等待任何一方的时间。不到 1 毫秒的时间以微秒显示，例如 180 µs。CSV 导出以 `request_upload_us`、`overhead_us` 和 `stream_processing_us` 三列包含这三项，单位为微秒。

失败的请求会显示其错误类型，例如**触发速率限制**、**上下文过长**、**超时**、**客户端已断开**或**客户端停止读取**。如果服务商返回了消息，也会一并显示。中途断开的流式回复会记录为失败，并注明进行到哪一步。

媒体请求会显示它发送和生成的内容，例如图片、朗读的字符数或音频、视频的时长，从不显示媒体本身。模型对请求生成的内容没有价格时（例如没有按片段定价的视频模型），其费用显示为**未知**，而不是 0 美元；导出文件的 `cost_known` 列也会说明这一点。价格设为 0 的模型（例如免费模型）的费用是已知的 0 美元。提供商按时长对音频计费却不报告时长时，Kaeso 会从文件头读取时长；此时费用会注明这一点，导出文件的 `cost_basis` 为 `measured`（[音频](../api/audio.md#费用和日志)）。Kaeso 在发送前拒绝的请求，以及被提供商拒绝或处理失败的请求，费用为 0 美元，也不计入用量；其日志仍会显示它请求的内容。断开连接的应用需为已发送给提供商的内容付费，实时会话则按结束前朗读或收听的内容计费。

发往别名的请求会显示**别名**。如果其路由发生了回退，**先尝试的模型**会列出在应答模型之前失败的步骤，以及每个步骤的状态和耗时，还有因刚刚失败而被跳过的步骤（[别名路由](../concepts/alias-routes.md)）。CSV 导出中对应 `alias` 和 `fallbacks` 两列。图片请求会显示**图片**：应用发送和服务商生成的数量，以及尺寸和质量；CSV 导出中对应 `media_unit`、`media_input`、`media_output` 和 `media_detail`。图片字节从不记录。语音请求会显示**语音**，即要朗读的字符数；转写请求会显示**音频**，即所转写音频的时长；两者都带格式。CSV 的 `media_unit` 为 `character` 或 `millisecond`。音频同样从不记录。视频会记录两次：启动记为 `videos` 或 `videos/remix`，结束记为带有费用的 `videos/completed`。两者都会显示**视频**，即片段数及其时长，并带有分辨率；CSV 的 `media_unit` 为 `video`，`media_output` 为生成的毫秒数。视频文件从不记录。

请求日志不保留媒体。应用在聊天请求中发送的，或模型在回复中返回的图片、音频、视频或文件，只记录其媒体类型和大小，图片还会记录尺寸。标签页把它显示为一行，例如**图片（PNG，1,024 × 768，1.2 MB），未保留**。工具调用的参数或回答中的媒体也按同样的方式记录。

**请求**和**回复**标签页需要**查看提示词和输出**权限。缺少该权限、未记录内容或内容已超过保留期时，标签页会加以说明。Kaeso 从不保留嵌入向量。如果回复以本控制台尚无法读取的格式记录（例如来自更新版本的网关），则按存储原样显示。

## 检查提示缓存

**Token 输入/输出 · 缓存**列末尾显示每个请求的输入中从提示缓存读取的占比，例如 `· 0%`。从未被缓存的长提示每次都按完整的输入价格计费。

Anthropic 只缓存请求用 `cache_control` 标记的提示部分；对于使用 OpenAI 格式的应用，Kaeso 会自行添加这些标记。以 Anthropic 格式发送、没有任何标记、且既未从缓存读取也未向缓存写入的请求，会以警告颜色显示其占比。其**用量**会显示**无缓存断点**，从而把缺少标记与缓存未命中区分开。部分 Anthropic 兼容服务商无需标记也会缓存；它们的请求只要从缓存读取或向缓存写入，就不会显示警告。

请求的**用量**还会列出**从缓存读取**，对于 Anthropic 格式，还会列出 Kaeso 发送的**缓存断点**数量。CSV 导出以 `cache_breakpoints` 列包含该数量。

在开启了[响应缓存](response-cache.md)的项目中，**用量**还会显示**响应缓存**的处理结果：应答了请求、将请求发给了服务商，或跳过了请求。CSV 导出以 `response_cache` 列包含该结果。

## 导出日志

**导出**会下载符合当前筛选条件的请求：

| 格式 | 内容 |
| --- | --- |
| CSV | 元数据，供电子表格使用 |
| JSON Lines | 元数据，每行一个请求 |
| JSON Lines（含内容） | 元数据，以及已存储的请求和回复 |

导出需要**导出日志**权限，含内容导出还需要**查看提示词和输出**权限。

在**工具**中，**导出**会下载符合那里筛选条件的工具调用，格式同样是这三种；含内容时，每个调用都带有已存储的参数和结果。文件名为 `kaeso-tool-calls-…`。

在 CSV 中，Kaeso 会把每个文本值放在双引号中。以 `=`、`+`、`-`、`@`、制表符或回车符开头的值前面会加上 `'`。包含 `;`、`|` 或制表符的值同样如此；这些分隔符之后紧跟上述字符时，也会在其前面加上 `'`。这样无论电子表格按哪个分隔符拆分，都会将其显示为文本，而不是作为公式执行。

## 保留期

每个组织在**组织设置** › **日志记录**下决定保留哪些内容以及保留多久：

| 设置 | 默认值 | 作用 |
| --- | --- | --- |
| 记录请求内容 | 开 | 是否随日志条目保留请求和回复正文 |
| 元数据保留期 | 90 天 | 日志条目保留多久 |
| 内容保留期 | 30 天 | 请求和回复正文保留多久。不会超过元数据保留期 |

缩短保留期需要您确认，确认后会立即删除更早的条目；延长保留期只对新条目生效。实例为新组织设定默认值，并设定组织可选择的最长保留期（见[实例设置](instance-administration.md#更改实例设置)）。更改这些设置或组织的内容日志需要**管理日志设置**权限，并需近期登录。

拥有**切换内容日志**权限时，项目可以在其**设置**中为自己关闭内容日志。组织关闭内容日志时，项目无法开启。

## 删除日志

**日志记录**下的**存储**标签页按项目显示组织保存的条目数量及所占空间。该标签页和**删除记录**标签页需要**查看日志存储**权限。

1. 在**删除记录**标签页上选择**删除日志**。
2. 选择若干整 UTC 日，以及所有项目或某一个项目。
3. 输入 `delete` 进行确认。

Kaeso 会永久删除这些日期的日志，用量和费用会保留。列表会将每次删除显示为**排队中**或**已完成**，同时最多有 10 个删除任务在等待。列表还会列出缩短保留期所触发的删除，显示为**缩短元数据保留期**或**缩短内容保留期**。失败后等待重新运行的删除会显示“正在重试：”及错误信息。删除日志需要**删除日志**权限，并需近期登录。
