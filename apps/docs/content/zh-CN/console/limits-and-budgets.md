限额让用量保持在设定的范围内，分为三个层级：项目、成员或服务账号，以及密钥。请求必须通过适用于它的每一项限额，即其密钥、成员和项目的限额。

## 类型

| 类型 | 计量 | 周期 |
| --- | --- | --- |
| 支出预算 | 美元，按模型价格计算 | 一天、一个月或总计 |
| Token 预算 | Token | 一天、一个月或总计 |
| 请求速率 | 请求数 | 滑动的一分钟 |
| Token 速率 | Token | 滑动的一分钟 |

天和月指 UTC 的自然日和自然月；总计永不重置。限额可以适用于所有模型，也可以只适用于某一个模型。

限额不能高于上一层级的同类限额：密钥的支出预算不超过其成员的，成员的不超过项目的。请求数和 Token 数为不超过 10^12 的整数；支出预算最高为 1,000,000,000 美元，最多九位小数。

## 硬性和软性预算

速率限制始终拒绝超出的请求。开启**用尽后拒绝请求**时，预算为**硬性**（新限额默认开启）：用尽后请求会被拒绝，直到周期重置。**软性**预算会放行请求，只发送提醒。

预算最多可在其额度的 10 个百分比处提醒，默认为 50%、80% 和 100%。每到一个提醒点，组织的所有者和管理员、项目的管理员，以及（对于密钥的预算）密钥所有者都会收到邮件，除非他们在账户中关闭了**预算提醒**。速率限制没有提醒。

## 添加限额

在项目的**限额**页面上选择**添加限额**：

1. **适用于谁？** 项目、某个成员或服务账号，或某个密钥。
2. **设置什么限额？** 类型、额度、周期和模型；对于预算，还有是否为硬性以及何时提醒。

页面列出每项限额及其已用量；**全部**、**项目**、**成员**和**密钥**分别只显示一个层级。成员、服务账号或密钥的限额也会显示在其侧滑面板中。

编辑限额可更改其额度；对于预算，还可更改提醒和是否为硬性。要更改类型、周期或模型，请移除该限额后重新添加。如果在页面加载后有其他人更改了该限额，保存时会提示并加载当前限额，以便重新进行更改。查看限额需要**查看限额**权限，更改限额需要**管理限额**权限。

## 应用看到的内容

被拒绝的请求会以应用自身的 API 格式收到状态码 429，消息中会指明是哪项限额：

- 超出速率限制时，消息说明何时可以重试，`Retry-After` 给出秒数；
- 预算用尽时，消息说明何时重置。

当仍在进行中的请求几乎用尽某项预算时，下一个请求会以 `Retry-After: 1` 被拒绝，直到这些请求完成。如果硬性预算在其周期内及之前 30 天内没有已完成的请求，则一次只运行一个请求，直到第一个请求完成，因为此时尚不知道一个请求的费用。

> [!NOTE]
> 限额在 Valkey 中计数。Valkey 无法访问期间，速率限制和软性预算会放行请求，硬性预算会以状态码 503 拒绝请求。
