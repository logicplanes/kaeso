应用和脚本使用 API 密钥调用 Kaeso。密钥属于某个项目中的一名成员或一个服务账号，并在该项目中以其权限行事。密钥自身的模型访问和限额可以进一步收窄其范围。

## 创建密钥

1. 在项目的 **API 密钥**页面上选择**创建密钥**。
2. **用途是什么？** 为密钥命名，例如 `checkout-web`。请求日志和提醒会显示该名称。在**所属**中选择自己或项目的某个服务账号。
3. **何时过期？** 选择 1、7、30 或 90 天、**指定日期**或**从不**。设置了日期的密钥在当天开始时（UTC）失效。
4. **可以调用什么？** 选择**模型调用**供调用模型的应用使用，选择**平台**供通过 Platform API 管理项目的脚本使用，或选择**模型调用和平台**两者皆可。
5. **模型和限额**，可选：选择密钥可调用的模型，并设置密钥自身的[限额](limits-and-budgets.md)。不设置时，密钥可调用其所有者可调用的模型，并受所有者和项目限额的约束。

随后**密钥已创建**会显示密钥，以及一个使用它的示例请求。密钥由 `sk-kso-` 加上 48 个字母和数字组成，之后控制台只显示其开头和结尾的几个字符。

> [!IMPORTANT]
> 请在关闭对话框之前复制密钥。Kaeso 只保存其哈希值，无法再次显示。如果尚未复制，控制台会在关闭前询问。

默认过期时间为 90 天，或允许的最长选项。组织或项目设置了密钥最长有效期时，更长的选项和**从不**会被隐藏。

创建密钥需要以下权限：

| 创建 | 权限 |
| --- | --- |
| 自己的密钥 | **创建自己的密钥** |
| 服务账号的密钥 | **创建服务账号密钥** |
| 带平台访问权限的密钥 | 另需**授予密钥平台访问权限**、控制台会话和近期登录；密钥无法创建此类密钥 |

为每个应用和每个环境分别创建密钥。这样其用量、日志和限额各自独立，停用一个密钥也不会影响其他内容。

## 查找和更改密钥

**有效**列出可用的密钥。**全部**还会列出已停用、已过期和已归档的密钥。列表上方的**密钥所有者**可只显示某个成员或服务账号的密钥。

选择一个密钥即可打开其侧滑面板。面板显示密钥的归属、访问权限、创建者和创建时间、过期时间、上次使用时间以及 ID。拥有**管理限额**权限时，可随时在此更改其**模型**和**限额**。

## 停用密钥

密钥侧滑面板的菜单提供三个操作：

| 操作 | 作用 |
| --- | --- |
| 停用 | 密钥立即失效。之后可以重新启用 |
| 启用 | 已停用的密钥恢复可用。由某人停用的密钥只能由人启用，在账户的 **API 密钥**中只能撤销自己执行的停用 |
| 归档 | 密钥永久失效。其历史记录会保留 |

更改自己的密钥需要**管理自己的密钥**权限，更改任何人的密钥需要**管理所有密钥**权限。

此外，密钥在过期、所属项目被归档，或所属成员离开项目或组织时也会失效。Kaeso 会在密钥过期前 7 天和 1 天发送邮件。邮件发给密钥所有者，服务账号的密钥则发给项目的管理员。每个人都可以在账户**通知**中的**即将过期的密钥**下关闭这些邮件。

您[账户](account.md)中的 **API 密钥**列出您在所有项目中的密钥，可在此停用、启用或归档。新密钥需在项目中创建。

## 平台密钥

平台密钥供管理整个组织的脚本和基础设施使用，例如 Terraform。平台密钥以 `sk-kso-org-` 开头。它在组织及其所有项目中以管理员角色的权限行事，且从不调用模型。

1. 在**组织设置**中打开**平台密钥**，选择**创建平台密钥**。
2. 填写使用该密钥的对象和过期时间。选项以及组织的密钥最长有效期与 API 密钥相同。

创建平台密钥需要**创建平台密钥**权限、控制台会话和近期登录。平台密钥的停用、启用和归档方式与 API 密钥相同，需要**停用平台密钥**权限；由某人停用的平台密钥只能由人启用。
