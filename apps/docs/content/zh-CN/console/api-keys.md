应用和脚本使用 **API 密钥**调用 Kaeso。密钥属于某个项目中的一名成员或一个服务账号，在该项目中以其权限行事，并可通过自身的模型访问设置和限额进一步收窄。

密钥的形式为 `sk-kso-` 后跟 48 个字母和数字。Kaeso 只保存其哈希值：控制台仅在创建时显示一次完整密钥，之后只显示其开头和结尾的几个字符。

## 创建密钥

在项目的 **API 密钥**页面上，选择**创建密钥**。

1. **用途是什么？** 名称，例如 `checkout-web`，以及密钥的归属：自己，或者在拥有**创建服务账号密钥**权限时，归属于项目的某个服务账号。
2. **何时过期？** 1、7、30 或 90 天后，指定日期，或**从不**。默认为 90 天，或允许的最长选项。设置了日期的密钥在当天开始时（UTC）停止工作。组织或项目可以设置最长有效期，此时更长的选项和**从不**会被隐藏。
3. **可以调用什么？**
   - **模型调用**：模型 API，供应用使用。
   - **平台**：Platform API，在此项目中以密钥所有者的权限行事，供脚本使用。
   - **模型调用和平台**：两者皆可。
4. **模型和限额**，可选：可调用的模型以及密钥自身的[限额](limits-and-budgets.md)。

然后复制密钥。对话框会显示一个使用该密钥的示例请求。创建自己的密钥需要**创建自己的密钥**权限；授予密钥平台访问权限还需要**授予密钥平台访问权限**权限，并需要近期登录过。

> [!TIP]
> 为每个应用和每个环境分别创建密钥。这样其用量、日志和限额各自独立，停用一个密钥也不会影响其他任何内容。

## 密钥的侧滑面板

选择一个密钥即可打开其侧滑面板：其归属、访问权限、创建者和创建时间、过期时间、上次使用时间以及 ID。拥有**管理限额**权限时，可随时在此更改其**模型**和**限额**。列表上方的**密钥所有者**可只显示某个成员或服务账号的密钥。

## 停用、启用、归档

密钥侧滑面板中的菜单提供以下操作：

| 操作 | 作用 |
| --- | --- |
| 停用 | 密钥立即停止工作；可随时重新启用 |
| 启用 | 已停用的密钥恢复工作 |
| 归档 | 密钥永久停止工作；此操作无法撤销 |

更改自己的密钥需要**管理自己的密钥**权限，更改任何人的密钥需要**管理所有密钥**权限。密钥在过期、所属项目被归档，以及所属成员离开项目或组织时也会停止工作。**活跃**列出可用的密钥；**全部**还会列出已停用、已过期和已归档的密钥，按状态分组。

即将过期的密钥会在过期前 7 天和 1 天通过邮件通知：发给密钥所有者，服务账号的密钥则发给项目的管理员。每个人都可以在账户的**通知**下关闭这些邮件。

## 所有项目中的密钥

账户中的 **API 密钥**列出自己在所有项目中的密钥，可在此停用、启用或归档。新密钥需在项目中创建。

## 平台密钥

组织设置下的**平台密钥**供管理整个组织的脚本和基础设施使用。平台密钥以 `sk-kso-org-` 开头，在组织及其所有项目中以管理员角色的权限行事，且从不调用模型。**创建平台密钥**需要填写名称和过期时间，选项相同，并受组织的最长有效期约束。创建平台密钥需要**创建平台密钥**权限，并需要近期登录过。平台密钥的停用、启用和归档方式与 API 密钥相同，需要**停用平台密钥**权限。

脚本如何使用密钥，请参阅 [Platform API](../api/platform-api.md#身份验证)。
