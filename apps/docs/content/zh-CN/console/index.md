控制台位于部署所用的域名下，例如 `https://kaeso.example.com`。使用邮箱登录：根据部署和所在组织允许的方式，可使用密码、邮件登录链接或单点登录（SSO）。

## 两种模式

**应用**是在组织及其项目中工作的地方。侧边栏显示组织的**概览**、**项目**和**服务商**，其下是组织的项目列表；进入项目后显示项目的**概览**、**试验场**、**API 密钥**、**请求日志**、**模型**、**限额**、**成员**、**服务账号**、**审计日志**和**设置**。

**设置**包含个人账户、所在组织的设置，以及（对实例管理员而言）部署的设置。在侧边栏底部的菜单中选择**组织设置**、**账户**或**实例**即可打开；同一菜单还可切换组织，并提供**退出登录**。

## 可见内容

可见内容取决于所拥有的权限。没有权限的页面不会出现在侧边栏中。无法执行的操作显示为禁用，其提示框会注明所需的权限以及谁可以授予该权限。[成员和角色](members-and-roles.md)介绍了权限。

部分敏感操作，例如添加服务商密钥或授予密钥平台访问权限，在上次登录超过 15 分钟时会要求重新登录。

## 搜索和快捷键

按 ⌘K 或 Ctrl+K 打开搜索：可前往任意页面，查找当前项目的密钥、模型、成员和服务账号，创建各类对象，切换组织或项目，以及更改主题。`c` 在当前页面上创建，`g` 加一个字母前往某个页面，例如 `g k` 前往 API 密钥，`?` 列出所有键盘快捷键。
