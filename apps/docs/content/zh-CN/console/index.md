控制台运行在部署的域名下，例如 `https://kaeso.example.com`。使用邮箱地址登录；登录页提供哪些方式，见[登录和单点登录](../self-hosting/sign-in.md)。

- [组织和项目](organizations-and-projects.md)：创建组织和项目，连接单点登录，并管理它们的设置。
- [成员和角色](members-and-roles.md)：邀请成员，为其分配角色和权限，并创建服务账号。
- [服务商密钥](provider-keys.md)：连接 OpenAI 和 Anthropic 密钥，并选择各项目使用哪个密钥。
- [模型和别名](models-and-aliases.md)：选择项目可调用的模型，并为其设置自己的名称。
- [API 密钥](api-keys.md)：为应用和脚本创建密钥，加以限制，并在需要时停用。
- [限额和预算](limits-and-budgets.md)：限制项目、成员或密钥的请求数、Token 和支出。
- [请求日志](request-logs.md)：查找任意请求，导出日志，并选择保留哪些内容。
- [试验场](playground.md)：并排比较最多四个模型。
- [账户和语言](account.md)：保护账户安全，并选择主题和语言。
- [实例管理](instance-administration.md)：管理部署的用户、组织、设置和更新。

## 熟悉界面

侧边栏显示组织的页面；在项目中工作时，显示项目的页面。侧边栏底部的菜单可切换组织，并打开**组织设置**、您的**账户**，以及（实例管理员可见的）**实例**。侧边栏显示哪些内容取决于您的[权限](members-and-roles.md)。

按 ⌘K 或 Ctrl+K 可搜索页面、密钥、模型和成员，创建内容，或切换组织或项目。没有输入框获得焦点时，单个按键也可使用，例如 `c` 在当前页面创建，`g` `k` 前往 API 密钥。按 `?` 可列出所有快捷键。

列表（例如 API 密钥或成员列表）只占一个 Tab 停靠点。用方向键或 `j` 和 `k` 在行之间移动，按 Enter 打开所选行。
