控制台运行在部署所用的域名下，例如 `https://kaeso.example.com`。使用邮箱地址登录，并视部署和组织的允许情况，使用密码、通过邮件发送的登录链接或单点登录；登录页提供哪些方式，见[登录和单点登录](../self-hosting/sign-in.md)。

## 侧边栏

侧边栏随当前工作位置而变化：

- **在组织中：** **概览**、**项目**和**服务商**，下方是组织的各个项目。
- **在项目中：** **概览**、**试验场**、**API 密钥**、**请求日志**、**模型**、**限额**、**成员**、**服务账号**、**审计日志**和**设置**，上方有返回组织的链接。

侧边栏底部的菜单用于切换组织，并可打开**组织设置**、自己的**账户**，实例管理员还可打开**实例**。**创建组织**和**退出登录**也在此菜单中。

## 权限

控制台显示的内容取决于自己的权限。没有权限的页面不会出现在侧边栏中。无权执行的操作会被停用，其提示框会说明所需的权限以及可以授予该权限的人。角色和权限的说明见[成员和角色](members-and-roles.md)。

部分操作要求在最近 15 分钟内登录过；执行前，控制台会要求重新登录：

- 在组织中：添加或更改服务商密钥、授予密钥平台访问权限、创建平台密钥、更改或要求单点登录、删除日志、转让所有权以及删除组织；
- 在自己的账户中：更改邮箱地址、首次设置密码、关闭双重验证、重新生成恢复码以及删除账户。

## 搜索和快捷键

按 ⌘K 或 Ctrl+K 打开搜索：跳转到任意页面；查找当前项目的密钥、模型、成员和服务账号；创建内容；切换组织或项目；或更改主题。

输入框没有焦点时，可使用单键快捷键：

| 按键 | 操作 |
| --- | --- |
| `c` | 在当前页面创建，例如在 **API 密钥**页面创建密钥 |
| `/` | 在当前页面搜索 |
| `[` | 折叠或展开侧边栏 |
| `g` `o`、`g` `k`、`g` `l`、`g` `m`、`g` `p` | 前往项目的概览、API 密钥、请求日志、模型或设置 |
| `g` `s`、`g` `a` | 前往设置或组织的审计日志 |
| `?` | 列出所有快捷键 |

列表（例如 API 密钥或成员）只占一个 Tab 停靠点。在列表内，上下方向键或 `j`、`k` 在行之间移动，Enter 打开所选行；右方向键进入该行的操作，左方向键或 Escape 返回。在可以选择行的地方（例如**添加模型**），空格键或 `x` 选择一行，Shift 加方向键扩展选择，⌘A 或 Ctrl+A 选择所有行，Escape 清除选择。页面上第一次按 Tab 会到达**跳到主要内容**，可跳过侧边栏。
