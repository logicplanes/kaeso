项目中的**工具**决定其门户提供哪些 MCP 服务器和工具，并把 claude.ai 等客户端连接到门户。查看此页面需要 `tools.view`，更改需要 `tools.manage`，调用工具需要 `tools.use`（[MCP 门户](../concepts/mcp-portal.md)解释了各个部分）。

## 开启工具

1. 打开项目的**工具**页面。**工具**标签页列出每个服务器的工具，以及服务器的连接和其中开启的工具数量。
2. 按名称或描述搜索工具，或按**服务器**、**状态**和**提示**筛选。**只读**和**破坏性**等提示是服务器的声明，并非保证。
3. 用工具的开关开启它，或用服务器标题处的**全部开启**开启该服务器的全部工具；**全部关闭**会再把它们关闭。工具的状态变为**开启**，门户会立即提供它。

显示**已变更**的工具在等待管理员在[组织的 MCP 服务器](mcp-servers.md#审核变更的工具)下审核其新定义，在此之前无法开启。选择一个工具，可以查看其详情、输入 schema、最近 7 天的调用，以及**查看调用**，它会打开按该工具筛选的[请求日志](request-logs.md)。

## 使用服务器

**服务器**标签页列出项目使用的服务器，以及它们的连接、开启工具的比例和最近 7 天的调用。

- **使用服务器**会添加组织的一个服务器。其工具一开始处于关闭状态。您还需要 `mcp_servers.view`。
- **停止使用**会把服务器的工具从门户中移除。再次使用时，所有工具都处于关闭状态。

## 连接客户端

**连接**标签页或页眉中的**连接客户端**会显示门户地址，例如 `https://kaeso.example.com/mcp/proj_…`，并带有复制按钮。

1. 选择客户端：Claude、ChatGPT、Cursor 或 GitHub Copilot。对话框会显示该客户端的步骤，并已填好地址。
2. 在客户端中添加该地址。客户端会打开您的浏览器，您在其中登录 Kaeso。
3. 检查客户端请求的内容，然后选择**连接**。同意页面会列出每个服务器以及客户端可调用的工具数量，展开后显示工具名称，并列出您仍需连接自己账户的服务器。

**已连接的客户端**列出有人连接的每个客户端、连接者、它接收登录的位置，以及连接时间和最近使用时间。**断开连接**会立即使其令牌失效。

您自己的智能体使用具有**工具**能力的 API 密钥调用门户。请在[创建密钥](api-keys.md#创建密钥)时开启它。

## 决定谁可以调用哪个工具

每个成员、服务账号和密钥只要拥有 `tools.use`，就可以调用项目提供的每个工具。要收窄范围，请打开该成员、服务账号或密钥，编辑其**工具**部分：关闭**项目提供的所有工具**，然后选择工具。密钥的工具始终在其所有者的工具范围之内。

## 在试验场中试用工具

在[试验场](playground.md)中，**工具**开关会把项目的工具发送给模型。模型请求调用时，回复会显示工具及其参数。**运行**会以您的身份调用工具，**跳过**会告诉模型您拒绝了。每个调用都决定后，回答会返回给模型。试验场中的调用和其他调用一样会被记录。
