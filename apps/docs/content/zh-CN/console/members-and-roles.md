组织中的每个人都有一个**组织角色**，并在其所属的每个项目中各有一个**项目角色**。角色是一组权限；还可以为成员单独添加或移除某项权限。[权限参考](../concepts/rights.md)列出了所有权限。

## 角色

| 组织角色 | 允许的操作 |
| --- | --- |
| 所有者 | 拥有所有权限，包括今后版本中新增的权限。只有所有者可以管理所有者，组织至少保留一位所有者。 |
| 管理员 | 管理组织和所有项目，但不能删除组织、转让所有权或更改账单 |
| 财务 | 账单，以及所有项目的用量和费用 |
| 开发者 | 创建项目，查看用量、费用和服务商密钥；在被添加到的项目中工作 |
| 审计员 | 为审查而读取整个组织，包括审计日志和所有项目，但不更改任何内容，也看不到提示词和输出 |
| 成员 | 查看组织及其成员；在被添加到的项目中工作 |

| 项目角色 | 允许的操作 |
| --- | --- |
| 管理员 | 管理项目：成员、密钥、服务账号、模型、限额、日志和设置 |
| 开发者 | 创建自己的密钥，使用这些密钥和在试验场中调用模型，读取项目内容，包括提示词和输出 |
| 查看者 | 读取项目的设置、模型、限额、密钥、用量和日志元数据，但不更改任何内容 |

所有者和管理员在每个项目中都拥有所有权限。在默认项目中，所有者和管理员以管理员身份加入，开发者以开发者身份加入，其他所有人以查看者身份加入。

### 自定义角色

在**组织设置** › **成员** › **角色**下，**创建角色**可为组织或项目创建自定义角色，可以从某个内置角色开始，也可以从零权限开始。组织角色还可以包含在所有项目中的权限。内置角色无法更改；可**复制**一个内置角色并以其为起点。一个组织最多有 50 个自定义角色，且已被分配给他人的角色无法删除。

只能授予自己拥有的权限，也只能更改其全部权限自己都拥有的成员。

## 邀请成员

组织**成员**页面上的**邀请成员**会通过邮件发送邀请：

1. 输入一个或多个邮箱地址。
2. 选择其在组织中的角色。
3. 添加其要加入的项目，并为每个项目选择角色。受邀者始终会加入默认项目。

邀请的有效期为 21 天。**邀请**列出所有邀请，可在此**重新发送**或**撤销**。启用了单点登录（SSO）的组织还可以让其邮箱域名下的人员无需邀请即可加入。

## 成员的侧滑面板

选择一名成员即可打开其侧滑面板：其中包括其角色及用于单独添加或移除权限的**自定义**、其拥有的每项权限及其来源、其所属项目，以及**从组织中移除**。所有者可以向其**转让所有权**，自己则成为管理员。

将某人从组织或项目中移除，会归档其在该处的密钥。

## 项目成员

在项目的**成员**页面上，**添加成员**会以某个项目角色添加已在组织中的人员；其他人需先邀请加入组织。项目成员的侧滑面板还可设置其可调用的模型及其[限额](limits-and-budgets.md)，**从项目中移除**会将其移出项目，但其仍留在组织中。

## 服务账号

**服务账号**是供软件而非个人使用的成员：后端、任务、流水线。其密钥不依赖于任何人是否留在组织中。

在项目的**服务账号**页面上，**创建服务账号**需要填写其用途，例如 `checkout-production`，以及其项目角色。其侧滑面板中包含其密钥（含**创建密钥**）、模型访问设置和限额。**归档服务账号**会永久归档该服务账号及其密钥。

## 模型访问

默认情况下，成员和服务账号可以调用目录中的所有模型，密钥可以调用其所有者可调用的所有模型。在其侧滑面板的**模型**下，可以改为选择特定模型。密钥永远无法调用其成员不可调用的模型：收窄成员的模型范围时，其密钥的模型列表也会相应收窄。更改模型访问设置需要**管理限额**权限。
