title: 实例管理
description: 管理整个部署的用户、组织和设置。

---

**实例管理员**负责运行部署。通过设置链接创建的第一个用户就是实例管理员，并可将其他人设为实例管理员。实例管理员在组织内没有任何权限：只能看到组织的元数据，看不到其密钥、日志或内容。

相关页面位于侧边栏底部菜单中的**实例**下。

## 用户

**用户**列出部署上的所有账户，包括活跃、已停用和已删除的账户。**邀请用户**可邀请某人加入部署而不加入任何组织；对方在被某个组织邀请后才会加入该组织。用户的侧滑面板提供以下操作：

| 操作 | 作用 |
| --- | --- |
| 实例管理员 | 将用户设为实例管理员，或取消其实例管理员身份 |
| 停用、重新启用 | 阻止登录、结束其会话并停用其密钥，或重新允许 |
| 结束会话 | 让该用户在所有地方退出登录 |
| 重置双重验证 | 移除其身份验证器应用和恢复码，用于两者都已丢失的情况 |
| 删除用户 | 移除其名称和邮箱地址，并归档其密钥；历史记录中显示为已删除的用户 |

结束会话或重置双重验证时，相关用户会收到邮件。

## 组织

**组织**列出所有组织及其成员、项目和状态。**创建组织**会以所选所有者创建组织；未选择所有者时，由自己担任所有者。

组织页面显示其元数据、所有者、成员和项目，以及最近 30 天的请求、Token、费用和存储的日志。**添加所有者**可将任何活跃用户设为所有者，包括自己（**添加我自己**）；实例管理员正是以此进入组织，此操作会记入该组织的审计日志。在此页面还可以重命名、删除和恢复组织；**立即删除**会立即删除已计划删除的组织，而不必等待宽限期结束。

## 设置

| 设置 | 选项 |
| --- | --- |
| 账户创建 | **仅限邀请**、**允许的邮箱域名**或**任何人**；受邀者始终可以创建账户 |
| 组织创建 | **仅实例管理员**、**允许域名下的用户**或**任何已登录用户** |
| 允许的域名 | 上述两项设置所用的域名；`*.example.com` 涵盖其子域名 |
| 组织删除 | 是否允许删除组织，以及宽限期（1 到 90 天） |
| 请求日志保留期 | 新组织的默认值，以及组织可选择的最长保留期 |

更改账户创建、组织创建或允许的域名需要近期登录。登录方式和邮件在网关的[配置](../self-hosting/configuration.md)中设置，此处只读显示；**发送测试邮件**可检查网关能否发送邮件。

## 模型来源

**模型来源**显示部署的 models.dev 数据：当前使用的数据、上次同步时间以及自动同步（默认每 24 小时一次）。**立即同步**会马上获取数据；如果无法访问 models.dev，则继续使用当前数据。

## 系统

**系统**显示网关的版本和状态、PostgreSQL、ClickHouse 和 Valkey 是否正常运行、请求日志缓冲区以及存储情况。页面每 10 秒检查一次，**立即检查**会马上检查。

## 更新

此安装正在运行的版本、最新的 Kaeso 版本及其之后所有版本的发布说明，以及网关上次检查的时间；设置侧边栏中 **更新** 旁的 **新** 标记表示有更新的版本。**立即检查** 会马上检查。页面中的设置可以关闭每天两次的检查、提供预发布版本，并通过[更新器](../self-hosting/upgrades.md#一键更新)开启一键更新。有更新器时，**更新到 …** 会在确认后更新此安装，并跟进每个步骤直到 Kaeso 恢复；没有更新器，或版本需要手动操作时，页面会显示命令和升级指南。历史中列出每次更新、发起人和结果。

## 审计日志

实例的**审计日志**记录对用户、组织和部署设置的更改，以及更改者和更改时间。
