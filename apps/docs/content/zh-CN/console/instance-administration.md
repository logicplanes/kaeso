---
title: 实例管理
description: 管理整个部署的用户、组织和设置。
order: 10
---

**实例管理员**负责运行部署。通过设置链接创建的第一位用户就是实例管理员；实例管理员可以将其他人设为实例管理员。实例管理员身份不授予组织内的任何权限：只能看到组织的元数据，从不包括其密钥、日志或内容。

这些页面位于**设置** › **实例**：在侧边栏底部的菜单中选择**实例**。

## 用户

部署上的所有账户，包括有效、已停用和已删除的账户。**邀请用户**会邀请某人加入部署，而不加入任何组织。用户的侧滑面板：

| 操作 | 作用 |
| --- | --- |
| 实例管理员 | 将用户设为实例管理员，或取消其实例管理员身份 |
| 停用、重新启用 | 阻止登录、结束其会话并停用其密钥，或重新允许这些操作 |
| 结束会话 | 让用户在所有位置退出登录 |
| 重置双重验证 | 移除其身份验证器和恢复码，适用于两者都已丢失的用户 |
| 删除用户 | 移除其姓名和邮箱并归档其密钥；历史记录中显示为已删除的用户 |

## 组织

所有组织及其成员、项目和状态。**创建组织**会创建一个组织，所有者为所选用户；未选择时，所有者为自己。

组织页面显示其元数据、所有者，以及过去 30 天的请求、Token、费用和日志。**添加所有者**可将任何有效用户设为所有者，包括自己；实例管理员正是通过这种方式进入组织，此操作会记录在该组织的审计日志中。在此还可以重命名、删除和恢复组织，或立即删除组织而不等待宽限期结束。

## 设置

| 设置 | 选项 |
| --- | --- |
| 账户创建 | 仅限邀请；允许的邮箱域名；任何人 |
| 组织创建 | 仅实例管理员；允许域名下的用户；任何已登录用户 |
| 允许的邮箱域名 | 用于上述两项设置的域名；`*.example.com` 涵盖其子域名 |
| 组织删除 | 是否可以删除组织，以及宽限期（1 到 90 天） |
| 请求日志保留期 | 新组织的默认值，以及组织可选的最长期限 |

登录方式和邮件在网关的[配置](../self-hosting/configuration.md)中设置，在此以只读方式显示。**发送测试邮件**可检查邮件设置。

## 模型来源

部署从 models.dev 获取的模型数据的状态：正在使用的数据、上次同步和自动同步（默认每 24 小时一次）。**立即同步**会刷新数据；如果无法从 models.dev 获取，则继续使用当前数据。

## 系统

网关的版本和状态，PostgreSQL、ClickHouse 和 Valkey 是否正常运行，以及请求日志缓冲区和存储。页面每 10 秒检查一次。

## 审计日志

对用户、组织和部署设置所做的更改，以及更改者和更改时间。
