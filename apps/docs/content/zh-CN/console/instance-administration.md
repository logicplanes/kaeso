实例管理员负责运行实例。通过设置链接创建的第一个用户就是实例管理员，并可将其他人设为实例管理员。实例管理员在组织内没有任何权限：您只能看到组织的元数据，看不到其密钥、日志或内容。

相关页面位于侧边栏底部菜单中的**实例**下。

## 管理用户

**用户**列出实例上的所有账户，包括有效、已停用和已删除的账户。**邀请用户**可邀请某人加入实例而不加入任何组织。对方在被某个组织邀请后才会加入该组织。

实例管理员带有**实例管理员**标记，**管理方**显示管理该账户的组织（见[受管理的账户](../self-hosting/sign-in.md#受管理的账户)）。选择一个用户即可打开其侧滑面板，其中列出其所属的组织及其在每个组织中的角色，并提供以下操作：

| 操作 | 作用 |
| --- | --- |
| 实例管理员 | 将用户设为实例管理员，或取消其实例管理员身份 |
| 停用、重新启用 | 阻止登录、结束其会话并停用其密钥，或重新允许 |
| 结束会话 | 让该用户在所有地方退出登录，并撤销其智能体 |
| 重置双重验证 | 移除其身份验证器应用和恢复码，用于两者都已丢失的情况；同时结束其会话和智能体 |
| 删除用户 | 移除其名称和邮箱地址，并归档其密钥。历史记录中显示为已删除的用户 |

当您结束某个用户的会话或重置其双重验证时，Kaeso 会通过邮件通知该用户。

## 管理组织

**组织**列出所有组织及其成员、项目和状态。**创建组织**会以您所选的所有者创建组织；未选择所有者时，由您担任所有者。

组织页面显示其元数据、所有者、成员和项目，以及最近 30 天的请求、Token、费用和存储的日志。您可以在此重命名、删除和恢复组织。

要进入某个组织，选择**添加所有者**并选择任意有效用户，或选择**添加我自己**。该组织的审计日志会记录此操作。对于已计划删除的组织，**立即删除**会立即删除它，而不必等待宽限期结束。

## 更改实例设置

在**常规**下：

| 设置 | 选项 |
| --- | --- |
| 账户创建 | **仅限邀请**、**允许的邮箱域名**或**任何人**。受邀者始终可以创建账户 |
| 组织创建 | **仅实例管理员**、**允许域名下的用户**或**任何已登录用户** |
| 允许的域名 | 上述两项设置所用的域名。`*.example.com` 涵盖其子域名 |
| 实例管理员的单点登录 | **无**，或一个启用单点登录的组织，其身份提供商可让该组织管理的实例管理员登录以管理实例（见[实例管理员](../self-hosting/sign-in.md#实例管理员)） |
| 时区 | 实例的时区。控制台中的所有时间都以此时区显示，对所有人都一样，自动更新也遵循此时区。**使用此时区**会切换到您浏览器的时区 |
| 组织删除 | 是否允许删除组织，以及宽限期（1 到 90 天） |

在**日志记录**下，**请求日志保留期**设置新组织的默认值，以及组织可选择的最长保留期。

更改账户创建、组织创建或允许的域名需要近期登录。更改实例管理员的单点登录需要使用密码或登录链接进行的近期登录；无法这样登录时，运维人员可在服务器上用 `kaeso instance admin-sso` 更改（见[运行 Kaeso 的命令](../self-hosting/installation.md#运行-kaeso-的命令)）。初始设置页面会把时区设为第一位用户的时区，用量图表仍按 UTC 日统计。

密码、登录链接和邮件在网关的[配置](../self-hosting/configuration.md)中设置。**常规**显示密码和登录链接是否开启，**系统**显示邮件，两者都只读。单点登录由每个组织在其**安全**页面上设置。**系统**上的**发送测试邮件**可检查网关能否发送邮件。

## 允许智能体

Claude Code 或 Codex 等智能体通过 [MCP 服务器](../api/mcp.md)代表其用户行事。在**常规**下，**智能体**部分包含实例的智能体策略：

| 设置 | 作用 |
| --- | --- |
| 允许智能体 | 默认开启。关闭后，任何智能体都无法登录，每个智能体在下一次请求时收到 403 |
| 实例上的最高权限 | **无**、**只读**、**配置**或**管理员**，限定实例管理员可以授予其智能体的实例权限。默认是**配置** |

只有实例管理员的控制台会话可以更改该策略；任何智能体都不能。智能体从不将某人设为实例管理员、更改实例管理员的单点登录，也从不立即删除用户或组织。[实例权限](../concepts/rights.md#实例权限)列出每项权限允许的操作。

## 同步模型数据

**模型来源**显示实例的 models.dev 数据：当前使用的数据、上次同步时间以及自动同步（默认每 24 小时一次）。**立即同步**会马上获取数据。如果无法访问 models.dev，则继续使用当前数据。

## 检查系统

**系统**显示网关的版本和状态，以及 PostgreSQL、ClickHouse 和 Valkey 是否正常运行。它还显示请求日志缓冲区、存储情况以及网关发送邮件的方式。页面每 10 秒刷新一次。

## 更新 Kaeso

**更新**显示实例正在运行的版本和最新的 Kaeso 版本，以及其间所有版本的发布说明。设置侧边栏中**更新**旁的**新**标记表示有更新的版本。网关每 5 分钟检查一次新版本，检查失败时页面会显示出来。

- **发布渠道**只提供稳定版，或同时提供预发布版本。只有网关的[配置](../self-hosting/configuration.md)能关闭这项检查，适用于无法联网的实例。
- 有[更新器](../self-hosting/upgrades.md#更新器)时，**更新的安装方式**可选择**手动**或**自动**。选择自动时，Kaeso 在更新窗口内安装新版本：每天或每周，在实例时区的某个整点。新的主版本或需要手动步骤的版本会等待您处理。
- 无论哪种方式，**更新到 …** 都会在您确认后更新实例，并跟进每个步骤直到 Kaeso 恢复运行。
- 没有更新器，或版本需要手动操作时，页面会显示命令和升级指南。

历史记录列出每次更新、其发起人（或**自动**）和结果。

更新后，每个打开控制台的人都会看到一次 **Kaeso 新功能**。它在专属且永不改变的配图上展示新版本及其改进，并可通过**下一个**浏览错过的每个版本。**继续**、Escape 键或点击外部区域会关闭它。**更新**页面上的**查看新功能**可再次显示当前运行版本的说明。

## 查看审计日志

实例的**审计日志**记录对用户、组织和实例设置的更改，以及更改者和更改时间。它像组织的审计日志一样标出智能体所做的更改，**智能体**筛选只显示这些更改（[查看审计日志](organizations-and-projects.md#查看审计日志)）。
