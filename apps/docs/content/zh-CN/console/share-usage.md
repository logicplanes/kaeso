共享链接向没有 Kaeso 账户的人（例如财务或经理）展示某个页面的数据。它可以保持最新，也可以保留创建当天的数据；过期或被您撤销后即失效。

## 可以分享什么

**分享**按钮位于各视图所在的位置：

| 分享内容 | 位置 | 链接显示的内容 |
| --- | --- | --- |
| 分析 | 组织或项目的**分析** | 该时间段的合计、所选指标与之前天数的对比图，以及按项目、模型、密钥、成员、路由和客户端划分的用量 |
| 成员统计 | **组织设置** → **成员**中某成员的详情 | 某成员的请求、Token、费用、缓存命中和趋势，按模型和项目划分 |
| 预算状态 | 项目的**限额** | 项目的限额和预算，以及已用量和预计走向 |
| 项目概要 | 项目的**概览** | 项目最近 30 天：请求、费用、错误率和主要模型 |

请求日志从不分享：其中可能包含提示词和回复。密钥、成员的地址或 ID 也不会分享。

## 选择链接显示的内容

**分享**对话框可设置：

- **标题**，显示在页面上。除非您隐藏了相应名称，否则它会写明项目、组织或成员。
- **数据。** **实时**在每次打开时显示最近的天数，天数与页面的时间段相同。**快照**保留该时间段当前的数据。
- **显示费用**，默认关闭。仅在您能看到费用时提供。
- **隐藏**成员名称、密钥名称和项目名称。隐藏的名称按请求数显示为*成员 1*、*密钥 2* 等。
- **谁**可以打开：**此组织已登录的成员**，或在组织允许时**任何持有链接的人**。
- **过期时间**：1、7、30 或 90 天后，或永不过期，但不超过组织的最长有效期。

链接只显示一次。Kaeso 只保存其哈希值，因此请在关闭对话框前复制它。

链接显示的内容永远不会超过创建者能看到的范围。每次打开时，Kaeso 都会检查创建者是否仍是成员，并且仍有权分享和查看链接显示的内容。创建者离开组织或失去这些权限后，链接即失效；如果只是失去了查看费用的权限，链接仍可使用，但不再显示费用。

## 共享页面

页面在 `https://kaeso.example.com/share/…` 打开，使用查看者的语言以及浅色或深色模式，适配手机和电脑。它不链接到控制台，并请求搜索引擎不要将其编入索引。聊天和帖子会显示图表的预览图。页面底部有一个小的**由 Kaeso 制作**标记，实例管理员可以将其关闭。

## 管理链接

**组织设置** → **共享链接**列出仍然有效的链接，包括其受众、创建者、查看次数、上次打开时间和过期时间。**撤销**会立即让链接失效。没有 `usage.share.manage` 时，您只能查看和撤销自己的链接。

在**组织设置** → **安全**中，**共享链接**可设置**允许共享链接**（**关闭**、**仅成员**或**任何持有链接的人**）和**最长有效期**。收紧策略也适用于之前创建的链接：选择**关闭**后它们失效，选择**仅成员**后需要成员登录。实例管理员可以为整个实例关闭共享链接（[实例管理](instance-administration.md#更改实例设置)）。

创建、打开和撤销链接都会记录在审计日志中。当有人分享链接时，拥有 `usage.share.manage` 的人会收到邮件，组织中订阅**安全设置已变更**的 Webhook 会收到 `share.created` 事件（[Webhook](webhooks.md)）。

## 权限

| 权限 | 允许 |
| --- | --- |
| `usage.share` | 分享自己能看到的内容，并撤销自己的链接。所有者、管理员、财务、开发者和成员拥有此权限 |
| `usage.share.manage` | 查看并撤销所有链接，并设置策略。所有者和管理员拥有此权限 |

分享组织的分析需要 `usage.org.view`，分享项目的分析或概要需要该项目的 `usage.view`，分享其预算需要 `limits.view`。分享他人的统计需要 `usage.org.view`；分享自己的则不需要其他权限。显示费用需要 `costs.org.view` 或 `costs.view`。

在 Platform API 中，`POST /platform/v1/orgs/{org}/shared-links` 创建链接，`GET` 列出链接，`DELETE …/shared-links/{link}` 撤销链接（[Platform API](../api/platform-api.md)）。连接到 Kaeso MCP 服务器的智能体会获得相同功能的工具（[MCP 服务器](../api/mcp.md)）。
