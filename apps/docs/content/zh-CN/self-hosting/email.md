网关自己通过 SMTP 发送每一封邮件：登录链接、邀请、密码重置、密钥到期提醒、预算提醒和安全通知。没有 SMTP 服务器时网关不会启动，除非您让它只记录邮件。

## 设置 SMTP

把 SMTP 服务器写进 `.env`：

```bash title=".env"
KAESO_SMTP_HOST=smtp.example.com
KAESO_SMTP_PORT=587
KAESO_SMTP_TLS=starttls
KAESO_SMTP_USER=kaeso
KAESO_SMTP_PASSWORD=…
KAESO_SMTP_FROM="Kaeso <kaeso@example.com>"
```

用 `docker compose up -d --wait` 应用。不设置 `KAESO_SMTP_FROM` 时，Kaeso 以您域名下的 `kaeso@` 发信，因此请设置一个 SMTP 服务器允许使用的发件地址。服务器不需要登录时，省略用户名和密码。[配置](configuration.md#电子邮件)列出了每项邮件设置及其取值。

## 发送测试邮件

1. 在控制台中打开**实例** › **系统**。**邮件**部分显示传输方式、SMTP 主机和发件人。
2. 选择**发送测试邮件**。邮件发给您自己，或发给您输入的地址。
3. 如果发送失败或没有收到，用 `docker compose logs gateway` 在网关日志中查看 SMTP 服务器的回应。

[故障排除](troubleshooting.md#收不到邮件)列出了常见原因。

## 不用邮件服务器试用 Kaeso

在 `.env` 中设置 `KAESO_MAIL_TRANSPORT=log`。网关随后只记录每封邮件的类型而不发送，从不记录收件人或内容。

密码登录仍然可用，`kaeso setup-link` 也照常打印设置链接。登录链接、邀请和提醒都不会送达。

## Kaeso 发送的邮件

| 邮件 | 发送时机 |
| --- | --- |
| 邀请 | 有人邀请某人加入组织 |
| 实例邀请 | 实例管理员邀请某人加入实例 |
| 登录链接 | 有人请求登录链接 |
| 密码重置 | 有人请求重置密码 |
| 邮箱变更 | 有人修改邮箱地址；发往新地址 |
| 邮箱变更请求 | 有人修改邮箱地址；发往当前地址，附带取消该更改的链接 |
| 注册 | 有人在实例允许时注册 |
| 密码已更改 | 密码发生变化 |
| 双重验证已开启 | 有人开启双重验证 |
| 双重验证已关闭 | 有人关闭双重验证 |
| 双重验证已重置 | 实例管理员或 `kaeso user reset-2fa` 重置了它 |
| 双重验证已锁定 | 有人连续输错 10 次双重验证码，此后每再输错 10 次也会发送 |
| 邮箱已更改 | 邮箱地址发生变化 |
| 已退出登录 | 某人的所有会话都已结束 |
| 账户已停用 | 实例管理员停用了账户 |
| 组织删除 | 组织被计划删除；发给其成员和实例管理员 |
| 所有权 | 有人把某人设为所有者 |
| 密钥到期 | 某人的某个 API 密钥即将到期 |
| 预算提醒 | 预算达到某个提醒阈值 |
| 测试 | 实例管理员发送测试邮件 |

安全通知和组织通知总会发送。每个人在**账户** › **通知**中选择接收哪些提醒，每封提醒的页脚都说明了如何关闭。

每封邮件都有 HTML 和纯文本两部分，并适配浅色和深色模式。邮件中的图片随邮件一起发送，因此不会从您的实例加载任何内容，也不含跟踪像素。

## 语言

每封邮件都有英语、德语和简体中文版本。Kaeso 为每个收件人选择语言：

| 收件人 | 语言 |
| --- | --- |
| 有账户的人 | 其在**账户** › **外观**中的选择。选择自动时，使用触发该邮件的浏览器的语言，否则为英语 |
| 还没有账户的人，收到邀请或注册链接时 | 邀请人或请求者的语言，否则为英语 |
| 密钥到期提醒、预算提醒和删除通知的收件人 | 每个收件人自己的选择，否则为英语 |

## 投递

邮件在网关内存中的队列里等待，最多 1,024 封，同时最多发送 16 封：

- SMTP 服务器暂时失败时，网关会在 1、5 和 30 秒后再试三次。
- 服务器永久拒绝某封邮件时，网关不再重试。
- 队列已满时，网关丢弃该邮件。
- 网关停止时，最多等待 10 秒发送队列中的邮件，仍未发出的会丢失。

网关会记录每封无法投递的邮件。`kaeso_emails_total` 按 `outcome` 统计邮件：`sent`、`failed` 或 `dropped`（[健康状态和指标](monitoring.md)）。
