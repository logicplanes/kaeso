Kaeso 会为登录链接、邀请、密码重置、密钥到期提醒、预算提醒和安全通知发送邮件。所有邮件都由网关自己通过 SMTP 发送。

## 设置 SMTP

把 SMTP 服务器写入 `.env`，然后用 `docker compose up -d --wait` 应用：

```bash
KAESO_SMTP_HOST=smtp.example.com
KAESO_SMTP_PORT=587
KAESO_SMTP_TLS=starttls
KAESO_SMTP_USER=kaeso
KAESO_SMTP_PASSWORD=…
KAESO_SMTP_FROM=Kaeso <kaeso@example.com>
```

| 设置 | 须知 |
| --- | --- |
| `KAESO_SMTP_TLS` | 端口 587 用 `starttls`，隐式 TLS（通常是端口 465）用 `tls`，`none` 只用于本地邮件捕获工具 |
| `KAESO_SMTP_USER`、`KAESO_SMTP_PASSWORD` | 服务器无需登录时两者都不填；设置密码时必须同时设置用户名 |
| `KAESO_SMTP_FROM` | 所有邮件的发件人，可写成地址或 `Name <address>`。默认为 `Kaeso <kaeso@` 加自己的域名；请使用 SMTP 服务器允许发信的地址 |

除非邮件只记录到日志，否则没有 `KAESO_SMTP_HOST` 时网关会拒绝启动。[配置](configuration.md#电子邮件)列出了所有邮件设置。

## 没有邮件服务器时

如果想在没有邮件服务器的情况下试用 Kaeso，设置 `KAESO_MAIL_TRANSPORT=log`。这样网关只记录本应发送一封邮件及其类型，从不记录收件人或内容。用密码登录仍然可用，`kaeso setup-link` 也照常输出设置链接，但登录链接、邀请和提醒永远不会送达。

## Kaeso 发送的邮件

| 邮件 | 主题 | 发送时机 |
| --- | --- | --- |
| 邀请 | {inviter} 邀请您加入 Kaeso 上的 {org} | 有人邀请某人加入一个组织 |
| 实例邀请 | {inviter} 邀请您加入 Kaeso | 实例管理员邀请某人加入该安装 |
| 登录链接 | 登录 Kaeso | 有人申请登录链接 |
| 密码重置 | 重置您的 Kaeso 密码 | 有人申请重置密码 |
| 更改邮箱地址 | 确认您的新 Kaeso 邮箱地址 | 有人更改邮箱地址；发送到新地址 |
| 注册 | 完成创建您的 Kaeso 账户 | 有人在实例允许的情况下注册 |
| 密码已更改 | 您的 Kaeso 密码已更改 | 密码发生更改 |
| 双重验证已开启 | 双重验证已开启 | 有人开启双重验证 |
| 双重验证已关闭 | 双重验证已关闭 | 有人关闭双重验证 |
| 双重验证已重置 | 您的双重验证已被重置 | 实例管理员或服务器上的 `kaeso user reset-2fa` 重置了双重验证 |
| 邮箱地址已更改 | 您的 Kaeso 邮箱地址已更改 | 邮箱地址发生更改 |
| 已退出登录 | 您已从 Kaeso 退出登录 | 某人的所有会话都被结束 |
| 账户已停用 | 您的 Kaeso 账户已停用 | 实例管理员停用了一个账户 |
| 组织删除 | {org} 已计划删除 | 某个组织被计划删除；发送给其成员和实例管理员 |
| 所有权 | 您现在是 {org} 的所有者 | 有人将某人设为所有者 |
| 密钥到期 | API 密钥 {key} 将于 {date} 过期 | 某人的一个 API 密钥即将到期 |
| 预算提醒 | {scope}的{budget}已用 {percent}% | 某个预算达到其提醒阈值之一 |
| 测试 | Kaeso 测试邮件 | 实例管理员发送测试邮件 |

安全通知和组织通知总会发送。提醒邮件会在页脚说明如何关闭；每个人在**设置** › **账户** › **通知**中选择接收哪些提醒。

## 语言

每封邮件都有英文、德文和简体中文版本，日期和数字按各语言的习惯书写。

| 收件人 | 语言 |
| --- | --- |
| 有账户的人 | 本人在**设置** › **账户** › **外观**中的选择；选“自动”时，用触发该邮件的浏览器的语言；否则用英文 |
| 还没有账户的人，收到邀请或注册链接时 | 邀请人或申请人的语言，否则用英文；已有账户的受邀者使用自己的选择 |
| 不经浏览器发送的邮件：密钥到期提醒、预算提醒、组织删除通知 | 每位收件人自己的选择，否则用英文 |

## 邮件的外观

每封邮件都采用控制台的样式：左上角是 Kaeso 字标，一个标题、一句话、最多一个按钮，以及注明安装名称的页脚。HTML 部分从不显示原始链接；纯文本部分内容相同，并给出完整链接。

- **浅色和深色。** 跟随系统深色模式的邮件应用，以及 Outlook.com 自带的深色模式，都会显示 Kaeso 的深色配色。自行反转颜色的应用会得到经过设计、反转后仍然清晰的浅色样式。
- **不加载外部内容。** 字标图片随邮件一起发送，因此总能显示，也从不从安装加载任何内容。邮件中没有 Web 字体、外部图片、脚本或跟踪像素。

## 投递

邮件在网关内存中的队列里等待，最多 1,024 封，同时最多投递 16 封。SMTP 服务器暂时失败时，网关会在 1、5 和 30 秒后再重试三次；服务器永久拒收某封邮件时，网关不会重试。无论哪种情况，无法投递的邮件都会记录到日志。网关停止时，最多等待 10 秒让队列中的邮件发出；届时仍未发出的邮件会丢失。

`kaeso_emails_total{kind, outcome}` 按 `outcome` 统计邮件：`sent`、`failed`，或在队列已满时为 `dropped`。参见[健康状态和指标](monitoring.md)。

## 测试

在控制台中打开**设置** › **实例** › **设置**。**邮件**部分显示传输方式、SMTP 主机和发件人；**发送测试邮件**会发一封给自己，或发给输入的收件人。如果发送失败或没有收到，网关日志中有 SMTP 服务器的答复，[故障排除](troubleshooting.md#收不到邮件)中有更多说明。
