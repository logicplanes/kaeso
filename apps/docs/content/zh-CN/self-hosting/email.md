Kaeso 会发送登录链接、邀请、密码重置、密钥到期提醒、预算提醒和安全通知等邮件。所有邮件都由网关自己通过 SMTP 发送。

## 设置 SMTP

将 SMTP 服务器添加到 `.env`，然后用 `docker compose up -d --wait` 应用：

```bash
KAESO_SMTP_HOST=smtp.example.com
KAESO_SMTP_PORT=587
KAESO_SMTP_TLS=starttls
KAESO_SMTP_USER=kaeso
KAESO_SMTP_PASSWORD=…
KAESO_SMTP_FROM=Kaeso <kaeso@example.com>
```

| 设置 | 须知 |
| --- | --- |
| `KAESO_SMTP_TLS` | 587 端口用 `starttls`，隐式 TLS（通常为 465 端口）用 `tls`，`none` 仅用于本地邮件捕获工具 |
| `KAESO_SMTP_USER`、`KAESO_SMTP_PASSWORD` | 服务器不需要登录时两者都不填；设置密码时必须同时设置用户 |
| `KAESO_SMTP_FROM` | 每封邮件的发件人，可以是一个地址，也可以是 `Name <address>`。Compose 文件将其设为 `Kaeso <kaeso@` 加上该安装的域名；请使用 SMTP 服务器允许发信的地址 |

所有设置都列在[配置](configuration.md#电子邮件)中。除非邮件只记录到日志，否则没有 `KAESO_SMTP_HOST` 时网关会拒绝启动。

## 没有邮件服务器时

如果想在没有邮件服务器的情况下试用 Kaeso，设置 `KAESO_MAIL_TRANSPORT=log`。这样网关只会记录本应发送一封邮件及其类型，从不记录收件人或内容。用密码登录仍然可用，设置链接也总会出现在网关的日志中；但登录链接、邀请和提醒都不会送达。

## Kaeso 发送的邮件

| 邮件 | 主题 | 发送时机 |
| --- | --- | --- |
| 邀请 | {inviter} 邀请您加入 Kaeso 上的 {org} | 有人邀请某人加入一个组织 |
| 实例邀请 | {inviter} 邀请您加入 Kaeso | 实例管理员邀请某人加入该安装 |
| 登录链接 | 登录 Kaeso | 有人申请登录链接 |
| 密码重置 | 重置您的 Kaeso 密码 | 有人申请重置密码 |
| 更改邮箱地址 | 确认您的新 Kaeso 邮箱地址 | 有人更改邮箱地址；发送到新地址 |
| 注册 | 完成创建您的 Kaeso 账户 | 有人在实例允许的情况下注册 |
| 密码已更改 | 您的 Kaeso 密码已更改 | 密码发生更改 |
| 双重验证已开启 | 双重验证已开启 | 有人开启双重验证 |
| 双重验证已关闭 | 双重验证已关闭 | 有人关闭双重验证 |
| 双重验证已重置 | 您的双重验证已被重置 | 实例管理员或服务器上的 `kaeso user reset-2fa` 重置了双重验证 |
| 邮箱地址已更改 | 您的 Kaeso 邮箱地址已更改 | 邮箱地址发生更改 |
| 已退出登录 | 您已退出 Kaeso | 某人的所有会话都被结束 |
| 账户已停用 | 您的 Kaeso 账户已停用 | 实例管理员停用了一个账户 |
| 组织删除 | {org} 已计划删除 | 某个组织被计划删除；发送给其成员和实例管理员 |
| 所有权 | 您现在是 {org} 的所有者 | 有人将某人设为所有者 |
| 密钥到期 | API 密钥 {key} 将于 {date} 过期 | 某人的一个 API 密钥即将到期 |
| 预算提醒 | {scope}的{budget}已用 {percent}% | 某个预算达到其提醒阈值之一 |
| 测试 | Kaeso 测试邮件 | 实例管理员发送测试邮件 |

安全通知和组织通知总会发送。提醒邮件会在页脚说明如何关闭它们；每个人可以在**设置** › **账户** › **通知**中选择接收哪些提醒。

## 语言

每封邮件都有英语、德语和简体中文版本，日期和数字按各语言的习惯书写。

| 收件人 | 语言 |
| --- | --- |
| 有账户的人 | 其在**设置** › **账户**中选择的语言；选择“自动”时，使用触发该邮件的浏览器的语言；否则为英语 |
| 还没有账户的人，收到邀请或注册链接时 | 邀请人或申请人的语言，否则为英语；已有账户的受邀者使用自己选择的语言 |
| 不经浏览器发送的邮件：密钥到期提醒、预算提醒、组织删除通知 | 每位收件人自己选择的语言，否则为英语 |

## 邮件的外观

每封邮件都采用控制台的外观：左上角的 Kaeso 文字标志、一个标题、一句话、最多一个按钮，以及注明该安装的页脚。HTML 中从不显示原始链接，纯文本部分则用相同的文字给出完整链接。

- **浅色和深色。** 跟随系统深色模式的邮件应用会得到 Kaeso 的深色配色；Outlook.com 自己的深色模式会得到相同的颜色值；自行反转颜色的应用会得到一个专为经受反转而设计的浅色版本。
- **不加载任何外部内容。** 文字标志图片随邮件一同传送，因此总能显示，也从不从安装中加载任何内容。没有网页字体、外部图片、脚本或跟踪像素。

## 投递

邮件在网关内存中的队列里等待，并逐封发送。投递失败的邮件会在 1、5 和 30 秒后再重试三次，之后放弃并记录到日志。网关停止时仍在队列中的邮件不会被发送。

指标 `kaeso_emails_total{kind, outcome}` 按 `outcome` 统计邮件：`sent`、`failed`，或在队列已满时为 `dropped`。参见[健康状态和指标](monitoring.md)。

## 测试

在控制台中打开**设置** › **实例** › **设置**。**邮件**部分显示传输方式、SMTP 主机和发件人；选择**发送测试邮件**，即可向自己或输入的收件人发送一封测试邮件。如果发送失败或没有收到，网关的日志会说明 SMTP 服务器的应答；[故障排除](troubleshooting.md#收不到邮件)中有更多内容。
