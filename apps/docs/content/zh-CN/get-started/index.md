从[快速开始](quick-start.md)入手：一个 Compose 文件即可从一台空服务器走到一个通过 Kaeso 调用模型的应用。

| 页面 | 内容 |
| --- | --- |
| [快速开始](quick-start.md) | 用 Docker Compose 启动网关、控制台和数据库，通过设置链接登录，添加服务商密钥、模型和 API 密钥，并发送第一个请求 |
| [调用模型](calling-models.md) | 在 Python 和 TypeScript 中使用 OpenAI 和 Anthropic SDK 调用模型、流式接收回复、使用 curl，以及在日志中查找请求 |
| [编程工具](coding-tools.md) | 将 Claude Code、Codex 等工具指向自己的安装 |

如果要参与 Kaeso 本身的开发，在本机从源代码运行所有组件，请改为参阅[本地环境搭建](../development/local-setup.md)。
