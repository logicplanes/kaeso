Start with the [quick start](quick-start.md): one Compose file takes you from an empty server to an app that calls a model through Kaeso.

| Page | What you do |
| --- | --- |
| [Quick start](quick-start.md) | Start the gateway, the console and the databases with Docker Compose, sign in with the setup link, add a provider key, a model and an API key, and send the first request |
| [Calling models](calling-models.md) | Call models with the OpenAI and Anthropic SDKs in Python and TypeScript, stream replies, use curl, and find a request in the logs |
| [Coding tools](coding-tools.md) | Point Claude Code, Codex and other tools at your install |

To work on Kaeso itself, with everything running from source on your machine, see [local setup](../development/local-setup.md) instead.
