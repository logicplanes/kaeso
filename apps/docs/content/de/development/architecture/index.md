Diese Seiten beschreiben, wie jeder Teil von Kaeso gebaut ist, für alle, die ihn gleich ändern wollen. [Die Einführung](../../index.md#wie-die-teile-zusammenspielen) zeigt, wie die Teile zusammenspielen, und [Ablauf einer Anfrage](../../concepts/request-flow.md) folgt einer Anfrage von außen.

## Nächste Schritte

- [Gateway](gateway.md): Folgen Sie einer Anfrage durch die Crates und lernen Sie die Regeln, denen der Rust-Code folgt.
- [Konsole](console.md): Sehen Sie, wie die Konsole Daten liest, Rechte prüft, ihren Code lädt und Fehler zeigt.
- [Dokumentations-Website](docs-site.md): Ändern Sie, wie aus Markdown-Seiten docs.kaeso.app wird.
- [E-Mails](emails.md): Ändern Sie die E-Mails, die das Gateway sendet.
- [Updates](updates.md): Ändern Sie, wie das Gateway Releases findet und wie der Updater sie prüft und anwendet.
