Kaeso läuft auf Ihrem Server als ein Docker-Compose-Projekt. Der [Schnellstart](../get-started/quick-start.md) installiert es; diese Seiten behandeln alles, was danach kommt.

## Einrichten

- [Anforderungen](requirements.md): Bemessen Sie den Server, öffnen Sie das Netzwerk und planen Sie Speicher für Anfrageprotokolle.
- [So funktioniert eine Installation](how-it-works.md): Sehen Sie, welche Dienste laufen, was jeder speichert und wie sie voneinander getrennt sind.
- [Installation](installation.md): Installieren Sie ein bestimmtes Release, probieren Sie Kaeso auf Ihrem Rechner aus und führen Sie seine Befehle aus.
- [Konfiguration](configuration.md): Schlagen Sie jede Einstellung nach und wohin sie gehört.
- [Domains und TLS](domains-and-tls.md): Stellen Sie Kaeso unter Ihrer Domain bereit oder hinter einem Proxy, den Sie schon betreiben.
- [E-Mail](email.md): Verbinden Sie einen SMTP-Server und sehen Sie, welche E-Mails Kaeso sendet.
- [Anmeldung und Single Sign-on](sign-in.md): Legen Sie fest, wie sich Personen anmelden, und kommen Sie wieder hinein, wenn nichts mehr geht.

## Betreiben

- [Upgrades](upgrades.md): Aktualisieren Sie auf ein neues Release, von Hand oder mit einem Klick.
- [Backups und Hauptschlüssel](backups.md): Sichern Sie die Datenbanken und Hauptschlüssel und rotieren Sie den Hauptschlüssel.
- [Zustand und Metriken](monitoring.md): Prüfen Sie den Zustand, lesen Sie Prometheus-Metriken ab und lesen Sie die Logs.
- [Fehlerbehebung](troubleshooting.md): Finden Sie die Lösung für ein Problem, das Sie sehen.
