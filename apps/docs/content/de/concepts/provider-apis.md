Suchen Sie einen Anbieter und sehen Sie, welche Modell-APIs von Kaeso seine Modelle erreichen. Jede Spalte verlinkt die Seite der API mit ihren Feldern, Limits und Kosten.

## So lesen Sie die Tabelle

- **Ja.** Kaeso ruft den Anbieter für diese API auf, mit den Modellen in der Zelle. Jedes Modell des Anbieters, das der Katalog des Projekts für die API führt, funktioniert; die Namen sind Beispiele.
- **Abgelehnt.** Der Anbieter bietet es an, aber Kaeso ruft es nicht auf. Kaeso antwortet mit 400, bevor etwas gesendet wird, und die Zelle nennt den Grund.
- **Nicht angeboten.** Die Dokumentation des Anbieters, in der letzten Spalte verlinkt, bietet keine solche API an.

Die Dokumentation der Anbieter wurde am 2026-11-09 gelesen. Die Quelle einer Zeile gilt für ihre Zellen, sofern eine Zelle keine eigene nennt.
