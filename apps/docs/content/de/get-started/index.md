Am besten mit dem [Schnellstart](quick-start.md) beginnen: Eine Compose-Datei führt von einem leeren Server zu einer App, die über Kaeso ein Modell aufruft.

| Seite | Was zu tun ist |
| --- | --- |
| [Schnellstart](quick-start.md) | Gateway, Konsole und Datenbanken mit Docker Compose starten, sich mit dem Einrichtungslink anmelden, einen Anbieter-Schlüssel, ein Modell und einen API-Schlüssel hinzufügen und die erste Anfrage senden |
| [Modelle aufrufen](calling-models.md) | Modelle mit den SDKs von OpenAI und Anthropic in Python und TypeScript aufrufen, Antworten streamen, curl nutzen und eine Anfrage in den Protokollen finden |
| [Coding-Tools](coding-tools.md) | Claude Code, Codex und andere Tools auf die eigene Installation ausrichten |

Wer an Kaeso selbst arbeiten will, mit allem aus dem Quellcode auf dem eigenen Rechner, liest stattdessen [Lokale Einrichtung](../development/local-setup.md).
