# Kaeso update service

The static site at [update.kaeso.app](https://update.kaeso.app): the release feed Kaeso installs read, the mirrored release manifests, every release's artwork and a page with every release and its notes. How installs upgrade is in [Upgrades](https://docs.kaeso.app/self-hosting/upgrades), and the rules for changing the service are in [AGENTS.md](AGENTS.md).
