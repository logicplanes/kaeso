# Kaeso console

The web console for the Kaeso gateway: people set up an install, sign in, and manage organizations, projects, members, API keys, provider keys, models and limits, compare models in the playground, and read usage and request logs. It is a static React app served on the same domain as the gateway, talks only to the Platform API, and is drawn with [`@logicplanes/kaeso-ui`](../../packages/ui) in English, German and Simplified Chinese. To run it from source, follow [Local setup](https://docs.kaeso.app/development/local-setup); how it is built is in [Architecture › Console](https://docs.kaeso.app/development/architecture/console), and the rules for changing it are in [AGENTS.md](AGENTS.md).
